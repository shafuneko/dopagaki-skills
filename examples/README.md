# examples/ — スキルの出力例（モック）

このディレクトリは**成果物の見本**を置く場所。`corpus/`（観察対象の素材）とは別物で、
ここにあるのは**このリポジトリの規則を使って作ったもの**。

- `corpus/` = 外の世界の素材（第三者の作品・実測データ）
- `examples/` = 内側の出力（スキルを適用して作ったモック）

## 置き方

```
examples/<slug>/
  index.html   ← 単一ファイルで動くこと
  notes.md     ← 何を作ったか、使った規則、規則にない判断、未実装
```

`index.html` は **外部依存なし**（CDN・画像・フォント読み込みなし。CSS と DOM だけで完結）。
ブラウザで開けば動く状態にする。スクリーンショットは `corpus/private/examples/<slug>-*.png`
（Git 管理外・Syncthing 同期）に置く。

## 満たすべき条件（`skills/dopagaki-direction` の適用例として）

1. **段階ラダーが3段以上**（L0 通常 / L1 予兆 / L2 リーチ / L3 発展 / L4 大当り / L5 確変 のうち3つ以上）。
   各段で「色・速度・レイヤ数・音・文字・抽選」のうち2つ以上が変わる。
2. **段階が画面に出ている**（今どの段階かが分かる。倍率・レベル・バー・保留色など）。
3. **虹色のモードを1つ選んでいる**（`R-style-rainbow-two-modes`: 終端記号か基調か）。notes.md に明記。
4. **止められる**（`R-intensity-preflight-choice`: 強度の事前選択、または停止ボタン。両方ならなお良い）。
5. **`prefers-reduced-motion` で動きが止まる**（色と光は残してよい）。
6. **閃光は1秒3回未満**（WCAG 2.3.1 の面積条件に触れない範囲。数値は `docs/02-taxonomy.md` 付録）。
7. **音を出すなら自動再生しない**（ユーザー操作の後に鳴らす。`R-*` の音の項を参照）。

## レビューの流れ

1. 作った人が `index.html` と `notes.md` を置く
2. 別の人が ego lite で開いて、上の7条件を確認し、
   `examples/<slug>/review.md` に「確認した条件 / 実測値 / 足りない点」を書く
3. 両方の確認が揃ったら、一覧の「状態」を `reviewed` にする
