## 登録形式

資料ごとに次の項目を記録する。原典を優先し、二次資料はその区別を明記する。

| 項目 | 記録内容 |
| --- | --- |
| 資料ID | 二者間で重複しないID。例: SRC-A-001（Aは担当者の識別子） |
| 書誌情報 | 題名、著者・発行元、公開日・版（不明なら不明と記載） |
| 原典の位置 | URLまたは共有ルートからの相対パスと、ページ・見出し・タイムコード等 |
| 確認状態 | 未入手／未確認／確認済。確認日も記載 |
| 要点 | 原文の転載を避け、制作に関係する内容を要約 |
| 適用範囲 | 定義、語彙、構成、視覚表現など、何の判断に使えるか |
| 留意点 | 資料の立場、他資料との相違、解釈上の不確実性 |
| 利用条件 | 引用・画像・再配布等の確認できた条件。不明は不明と記載 |

## 制作への対応付け

採用した指針には「指針／資料IDと該当箇所／適用範囲」を残す。制作者の解釈や試案は、その旨を明記する。相反する資料は一方を黙って消さず、対象・時期・文脈の違いを整理する。

大容量の原本や配布条件が不明な資料は、台帳への登録だけで共有先へ複製しない。共有可能な原本を置く場合は、台帳から相対パスで参照する。
