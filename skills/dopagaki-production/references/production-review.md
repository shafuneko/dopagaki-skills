# 制作チェック

制作物の形式と依頼に関係する項目を確認する。

- 目的・対象読者・使用場面・納品形式に合っているか。
- ドパガキ固有として扱った要素に資料上の根拠があるか。試作上の創作を確定事項にしていないか。
- 複数資料を使った場合、各資料がどの判断に寄与したか説明できるか。
- 引用と要約が区別され、素材の利用条件が今回の使い方と整合するか。
- 文章なら語調・構成・読みやすさ、画像や画面なら視認性・要素の一貫性など、形式に応じた確認をしたか。

制作メモには、採用資料ID、主な表現判断、仮定、完成に影響する未解決点を必要な範囲で記す。骨組みだけを作った場合は、資料に基づく完成版と誤認されないよう状態を伝える。
