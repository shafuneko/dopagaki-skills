# パチンコ・スロットの演出文法（Web に移植するための語彙）

出典つきの詳細は [`research/20261116-pachinko-slot-grammar.md`](../../../research/20261116-pachinko-slot-grammar.md)（303行、出典ラベル分離）と
[`research/20261116-spectacle-cases.md`](../../../research/20261116-spectacle-cases.md)（実機・実作品の事例）を参照。
ここは「Web の演出に移植する形」に絞った要約。**数値は出典側の条件（機種・母数）を必ず確認する。**

## 0. 前提（ここを間違えると全部ずれる）

- 演出は**結果の事後開示**。演出が出たから当たるのではなく、抽選は既に終わっている。
- 「信頼度」は**条件付き割合**（その演出が出たときの当たり率）で、大当り確率・占有率・出現率とは母数が違う（ppps.jp）。
- **複数演出の信頼度は足し算できない**（赤保留60%＋チャンスアップ50%≠110%）。
- 「激アツ」「大当り濃厚」「確定」は固定の%ではない。機種・文脈で変わる。
- **演出と賭博性は別問題。** Web に移植するのは「見た目と時間の設計」だけ。景品・換金・確率を伴う設計は別途、景表法・各プラットフォーム規約の確認が必要。

## 1. 段階のラダー

| 段階 | 呼称の例 | 何が起きるか | Web での対応 |
|---|---|---|---|
| L0 | 通常変動 | 図柄が回るだけ。基準状態 | 待機・ローディング・通常表示 |
| L1 | 予告 / 先読み | 小さな違和感。色が1つ変わる、音が1つ増える | 初回だけの装飾、ホバーの変化 |
| L2 | リーチ | 図柄が揃いかける。テンポが上がる | プログレスが伸びる、数字が揃いかける |
| L3 | 発展 / カットイン | 画面構成が変わる。別レイヤが乗る | モーダル、全画面遷移 |
| L4 | 大当り | 虹色・閃光・集中線・文字・音が同時に開く | 成功画面、購入完了、ドロップ獲得 |
| L5 | 確変 / RUSH / AT | 状態として続く。BGM・色・倍率が高いまま | セール中、イベント期間、連続ドロップ |

- 段階数は実機でも **4〜5 に揃う**（5段階ラダー、SU1〜5、3段階＋予告）。
- **L3 で一度止める**（暗転・間・BGM 停止）。実機でも「無演出」や「ひと休み」画面が落差に使われる（パチスロナイツは リーチ目出現ゲームの約30%が無演出）。
- パチンコの「確変/ST/RUSH」は**状態**、スロットの「上乗せ」は**連続量**。Web では「期間（状態）」と「積み上げ（数値）」を分けて設計する。

## 2. 仕掛けの語彙

| 用語 | 意味（一般的な用法） | Web への移植 |
|---|---|---|
| 保留 | 次の変動を溜める枠（最大4個など）。**保留 ⊃ 先読み**（先読みは保留変化の一種） | キューの UI（最大 N 個、消化で減る） |
| 先読み | 変動が始まる前に出す予告 | 事前シグナル（一度だけ光る、音が1つ鳴る） |
| カットイン | 画面に割り込む一瞬の別カット | 全画面オーバーレイ 200〜400ms |
| 全回転 | 図柄が全部回る派手な演出。**大当り濃厚**だが「RUSH まで確定」とは別 | 全面のグラデ回転＋集中線 |
| 復活演出 | 一度外れたように見せてから当たる | 失敗表示 → 300ms 後に反転 |
| 再抽選 / 図柄昇格 | 当たり後の格上げ。復活とは別軸 | 結果表示の格上げ |
| 確変 / ST / RUSH | 当たり後の高確率状態 | セール継続・倍率持続 |
| 信頼度 | その演出が出たときの当たり率 | コピーの強度（「ほぼ確」「確定」） |
| テンパイ | スロットで2リール停止＝パチンコのリーチに相当 | 2/3 が揃った状態の表示 |

**注意**: 確率・信頼度は機種依存。**数値を書くときは必ず出典と母数を付ける。**

## 3. 派手さの手段（実機で使われるもの）

段階は「色」で符号化されるのが定番（白 → 赤 → 虹）。虹は**終端記号**で、その上に例外を1つ置く（覚醒目など）。

- **虹色（レインボー）**: エヴァ15 では「虹保留＝確変当り濃厚」「虹ランプ＝確変当り濃厚」。**最上位の記号**として温存されている。
- **白フラッシュ**: 当たりの瞬間。1回。連射しない。
- **集中線**: eFガンダムSEED クライマックスでは「最終あおりの集中線デフォルト70.9% / 赤90%over」。**集中線の有無が期待度の記号**になっている。
- **画面ブレ（揺れ）**: 同機種で「画ブレ なし82.0% / あり90%over」。揺れも記号。
- **画面分割・レイヤ追加**: 発展の合図。
- **文字（テロップ）**: 極太・縁取り・傾き。実務値は [docs/02-taxonomy.md](../../../docs/02-taxonomy.md) 付録（4文字/秒・16文字/行・2行）。
- **音**: 段階が上がると音数が増える。**1動作1音**。
- **操作の組み込み**: レバー・ボタン連打・長押し。Web では「押すと回る」「長押しで発展」。
- **強度の事前選択**: dopa-pong は起動時に「SUPER DOPA モード」の確認ダイアログを出し、「虹色の残像や爆発で、試合の演出が派手になります」「強い光や揺れにより、画面酔いや発作などが起きるおそれがあります」「あとからゲーム設定で切り替えられます」と明示する。
  → **強度を最初にユーザーへ委ねる**设计（H9 の実例）。Web でも最初に強度を選ばせるのが安全。

## 4. 移植するときの原則

1. **記号の温存**: 虹・白閃光・集中線は「ここぞ」で使う。全部を虹にすると記号が死ぬ。
2. **段階の可視化**: 今どの段階かを画面に出す（倍率・レベル・バー・保留色）。dopa-pong の FEVER LEVEL が実例。
3. **非線形の上がり幅**: ×1→2→5→20→100、0.5%→1.5%→91%。**差が大きいほど最後の一撃が強い**。
4. **外れの設計**: 外れても「惜しかった」が残る（リーチ止まり）。Web では「もう少しで達成」。
5. **止められる**: L5 を置いたら停止ボタン。強度と制御は独立（H9）。

## 5. 実例（このリポジトリの観察から）

- **dopa-pong**: DOPA SLOT（D/O/P の3リール）＋ FEVER LEVEL 5段（×1/×2/×5/×20/×100、境界 0-4/5-9/10-19/20-29/30+）＋ アイテム抽選 `0/100`。ポーズ画面「TAKE A BREATHER」。
  → [`observations/O-20261116-play-dopa-pong.md`](../../../observations/O-20261116-play-dopa-pong.md)
- **ドパ麻雀（dopa.rotenkogames.com）**: タイトルから虹色が**様式として全面**（ロゴ・サブタイトル・ボタン・背景の光条）。パチンコの「虹＝終端記号」とは逆の使い方で、この2型を混ぜないための規則が `R-style-rainbow-two-modes`。説明文は5行・1行20〜30字で、極太＋白フチ＋黒縁。
  → [`observations/O-20261116-play-dopa-mahjong.md`](../../../observations/O-20261116-play-dopa-mahjong.md)
- **ドパWick**: タイトル背景の色相巡回（0.4秒ごとに全面の色が変わる、周期約2.4秒、彩度・輝度はほぼ一定）。
  → [`observations/O-20261116-play-dopa-wick.md`](../../../observations/O-20261116-play-dopa-wick.md) §8
- **ドパガキ氷**: BGM 停止 →「本編開始しますか」の落差。
  → [`observations/O-20261116-case-dopagaki-signs.md`](../../../observations/O-20261116-case-dopagaki-signs.md)
- エヴァ15・パチスロナイツ・eFガンダムSEED の数値 → [`research/20261116-spectacle-cases.md`](../../../research/20261116-spectacle-cases.md)
- CSS/SVG での実装コード（虹・集中線・閃光・グリッチ・揺れ）→ [`spectacle-recipes.md`](spectacle-recipes.md) と
  [`research/20261116-spectacle-techniques.md`](../../../research/20261116-spectacle-techniques.md)（T01–T22、**未検証**）
