## 何をしたか

1. 作品ページを開き、ページ全体のスクショ（dopamine-01.png）。紹介文に「第1回Gamma Game Jam 参加作品／お題：ドパガキ／製作期間 1週間」。
2. ページ内 iframe の src を直接開き（unityroom のラッパーを外す）、9秒待機 → 夜空と山のシーン（dopamine-02.png、この時点ではUIなし＝ロード中と解釈）。
3. (960,500) をクリック → 直後にネオンサインのタイトル画面（dopamine-03.png）。中央に光る "DopaMINE" の看板、下部に「ー クリックでスタート ー」、左右に建物のシルエット。
4. タイトル画面の静止を確認するため 1秒間隔で6枚撮影 → **6/6 が同一ハッシュ**（＝タイトル画面は完全静止。背景アニメ無し）。
5. (960,400) をクリック → 2.5秒後にスクショ（dopamine-04.png）。赤い文字が走査線状に歪む演出（「投入禁止」「潰しますよ」）と紫の光の柱、"Max:5,000,000,000,000" の表示。**オープニング/導入演出**と解釈。
6. その後 1秒間隔で6枚撮影 → **6/6 すべて異なるハッシュ**（毎秒変化）。
7. (960,300) をクリック → dopamine-05.png、1.3秒後に dopamine-06.png。ここで**プレイ画面**に到達: 上部に "20 DP" の通貨カウンタ（ピンクのバー）、左上に "SHOP" の看板（注射器・ツルハシ・ヘルメットのアイコンと、まんじゅう型の作業員の顔）、右に "B1F" の看板と光る採掘ポイント、下部に坑道。作業員スプライト2体（青・紫）がそれぞれピンクのバー（進捗/体力）を持つ。左側にピンクの光の粒が上昇、左下に光る「E」のオブジェクト。
8. プレイ画面で 0.5秒間隔10枚撮影 → 8/10 が異なるハッシュ（同一値は非隣接で2回）。**0.5秒ごとに約0.9回の画面変化**。
9. (150,120) の SHOP をクリック → dopamine-07.png、続けて (500,300) をクリック → dopamine-08.png。合計プレイ時間は**約10秒**（演出込みで約15秒）。
10. 15:38 打ち切り（時間上限）。

## 印象（主観）

ネオンと赤い走査線の導入演出が妙に凝っていて、「演出を眺めさせてから作業をさせる」順序がはっきりしている。プレイ画面は落ち着いた暗い坑道で、派手な点滅は無い。20 DP という小さい数字が最初に見えるので「増やす」動機は分かりやすい。
