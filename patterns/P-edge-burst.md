# P-edge-burst — 刺激は量の持続ではなく、区間の端（開始0〜3秒と終端）での急変として設計され、端の外では刺激量を落とす

## 傾向

強く知覚される刺激は、作品中ずっと高いのではなく、**区間の端で量を急変させる**形で置かれる。
観察された端の作り方は3つ: (a) 開始直後の落差、(b) 局所区間だけの高密度化、(c) 終端を開始に一致させて「終わり」を消す。
いずれも「直前の静／低刺激」を基準点として要求する点が共通する。

支持する記述:

- ライラックは「ささやく高音ギター → ヘヴィなディストーション → 歌い出しで一斉に小音量」という**冒頭の音響落差**を持つ。ドパガキ氷は完成時に全画面フラッシュと文字演出を出した直後、**BGM を止めて**「本編を開始しますか」と提示する（`O-20261116-case-dopagaki-signs` S-1 / S-4 / S-5。いずれも二次記述由来）。
- 『ボーン』系で 1秒を切るのは作品平均ではなく**戦闘シーケンス等の局所**（0.58秒）。平均 ASL 2.4秒の作品が「速い」と評されるのは、0.5秒台の連続区間の位置による（`O-20261116-video-asl-cuts` S-1 / S-4。0.58秒は文献値）。
- ショート動画のフックは **0〜3秒**、パターン割り込みは**最初の0.8秒以内**、ループは**最終フレーム＝最初のフレーム**。どちらも「時間軸の端」を操作する技法（`O-20261116-video-caption-rate` S-4。記事の記述のみ）。

## 現れる条件

- 端の直前に**低刺激の基準点**がある（ささやく導入、4秒台のショット、無音、静止）。
- 端が画面または音の**全画面・全音量**で起きる（サイズの急変が同時に起きる）。
- 高密度区間が**局所**に限定されている（全体平均を上げない）。区間の長さは観察例で 0.5〜3秒。
- 終端を開始に一致させられる構造（ループ可能な尺、最終フレームを最初に合わせられる編集）。

## 現れない条件

- 常時ループで端が存在しない、または端が画面外にある（gumroad の 20〜80秒の帯は端が見えない連続で、落差ではなく持続。`O-20261116-fe-gumroad-density` S-3）。
- 落差の基準点が無い（最初から最大音量・最大密度で始まり、その後も同じ）。
- 尺が長く、端と端の間隔が数分ある（端の効果が局所に閉じる）。
- 端の急変が知覚閾以下（音量差・輝度差が小さい）。**閾値は未測定**。

## 実装上の対応物

- **開始の落差**: 最初の 0〜0.8秒に `animation` の短い区間を置き、0.8〜3秒で一度 duration を伸ばす。音なら冒頭 1〜2秒を低音量（`gain 0.2` 相当）にし、3秒で全音量へ。
- **局所バースト**: 全体の `transition-duration` を上げるのではなく、区間指定で短い duration を集中させる。動画なら 0.5〜1秒のショットを 8〜12連（観察例 0.58秒、10連発の記述）。
- **終端の一致**: `@keyframes` の 0% と 100% を同一フレームにし、`animation-iteration-count: infinite`。テロップなら最終フレーム＝最初のフレームの静止画。
- **遮断**: 刺激の直後に `audio.pause()` 相当で無音へ落とし、テキスト1行だけ残す（ドパガキ氷の「本編を開始しますか」型）。落差の振幅は「直前の最大値 − 直後の値」で測る。
- 観察元の数値: フック 0〜3秒、パターン割り込み 0.8秒以内、局所ショット 0.58秒、全体 ASL 2.4秒 / 2.0秒。

## 反例

- **gumroad**: 20〜80秒の常時ループは端の無い持続で、端の急変を使っていない。しかも「ドパガキ的」と読める密度を出している（`O-20261116-fe-gumroad-density` 反例節）。端は必須ではない。
- **ライラック**: 音澤の分析では拍子変化はCメロのみ、転調はBメロとラストサビ以降、構成は J-POP の王道の反復。「脈絡のない情報の連続」ではなく、端の落差だけでも説明できない（`O-20261116-case-dopagaki-signs` 反例節）。
- **フック3秒**: 「3秒でフックできないと伸びない」という主張の根拠は記事側にも測定が示されていない（`O-20261116-video-caption-rate` 反例節）。0〜3秒離脱層と10秒以降離脱層が混ざる可能性があり、端の位置の効果は**未確認**。
- **ドパガキ氷**: 刺激を売りにしながら完成後に BGM を止める。「刺激の持続」を目的としない反例であり、同時に「遮断を演出に使う」支持例でもある（同じ観察が両側に効く）。

## 強度の分布

- **強い**: ドパガキ氷の完成演出（全画面フラッシュ＋文字＋直後の無音）。落差の振幅が最大で、複数チャネル（光・音・文字）が同時。
- **中**: ショート動画のフック＋ループ（端は操作するが、振幅は編集のみ）。
- **弱い**: ライラックの冒頭（音響の落差はあるが、以降は王道構成で反復）。
- **逆**: gumroad（端を使わず、長い帯の持続で密度を出す）。
