# P-switch-rate-over-mean — 「速い」の体感は遷移時間・ショット長・文字速度の平均（中央値）ではなく、単位時間あたりの切替回数と短い側に偏った分布で決まる

## 傾向

同じ平均値でも体感が揃わない、という報告が4件の独立した観察で一致した。体感に対応しているのは
(a) 単位時間あたりの切替回数、(b) 切替間隔の分布のうち短い側（下方テール）の厚み、の2つで、
平均・中央値は分布が単峰のときだけ代表値として使える。

支持する記述（各観察の該当箇所）:

- ASL（平均ショット長）は **分あたりカット数の言い換え**（60 ÷ ASL）であり独立指標ではない。2.4秒=25カット/分、2.0秒=30カット/分。1秒を切るのは作品平均ではなく**局所区間**（0.58秒）。平均は「全部2.4秒」と「4秒のあと0.5秒が10連発」を区別しない（`O-20261116-video-asl-cuts` S-2 / S-4）。
- ショート動画の実務値 150〜200語/分は文字数換算で約 15〜20cps で、Netflix の上限 20cps と同じ帯。**cps を上げずに 1画面の語数を 1〜3語へ削ることで切替頻度を上げている**（`O-20261116-video-caption-rate` S-2 / S-3。ただし実務値は記事の記述のみ）。
- gumroad は `transition-duration` の中央値 150ms だが、常時ループは 20/60/80秒。**平均を取ると二峰性が中間値に潰れる**（`O-20261116-fe-gumroad-density` S-2 / S-3、反例節）。
- tinybird は省略記法19件のうち 300ms が9件で最多なのに、宣言ベースの中央値は 200ms。**短い側の裾（1ms×3、100ms×2）が中央値を引き下げている**（`O-20261116-fe-tinybird-hardborder` S-2）。

## 現れる条件

- 切替の総数が多く、かつ間隔の分布が短い側に厚い（下方テール）。
- 1画面あたりの情報量を削って切替回数を上げている（1語テロップ、短いショットの連続）。
- 同一画面に**速い応答**（100〜300ms）と**遅い常時ループ**（20〜80秒）が併存し、単一の平均では表せない。
- 計測が宣言ベース（CSS テキストの正規表現集計）で、`var()`・省略記法・`animation-duration` の宣言分散が残っている（分布の山を取り違えやすい）。

## 現れない条件

- 遷移時間が少数の段階値に量子化され、分布が単峰のとき（tinybird: 省略記法19件中 300ms が9件）。この場合は中央値が体感の代表値として機能しうる。
- 切替回数を増やさず、1回あたりの情報量だけを増やす場合（cps を上げる）。caption の観察では、これで「速く」はならないと読める（ただし解釈を含む）。
- 画面の変化が1種類しかない静的なページ（観察に該当例なし＝**未確認**）。
- 作品の尺が短く、終端が必ず来る場合（切替回数の効果より「終わる」ことの効果が勝つ可能性。未検証）。

## 実装上の対応物

計測（どの数値を見るか）:

- `transition-duration` / `animation-duration` の**中央値ではなく分布**: 全宣言を ms に正規化し、10/50/90パーセンタイルとヒストグラムを出す。実効値は `document.getAnimations()` の `effect.getTiming().duration` を全件集める（宣言ベースとの差を埋める）。
- **切替回数/秒** = `@keyframes` 内の変化点（同一プロパティの値が変わる箇所）の数 ÷ duration。テロップなら DOM の差し替え回数/秒。
- **下方テールの厚み** = duration が 150ms 未満の件数 ÷ 全件。ASL なら 10パーセンタイルのショット長。
- 観察元に現れた実数（すべて観察ファイル記載の値。測り方は各ファイルの「測り方」列）:
  150ms（gumroad、`transition-duration` 6件の中央値。min 30 / max 300）、
  300ms（tinybird、省略記法19件中9件）、
  20/60/80秒（gumroad、`animation:` 省略記法の時間値）、
  ASL 2.4s = 25カット/分、2.0s = 30カット/分、局所 0.58s、
  20cps / 42文字 / 最大2行 = 1画面 最大84文字、1語テロップ 150〜200語/分。

実装（**案。効果は未検証**）:

- 平均を下げるのではなく、短い duration の要素を**数で**増やす（例: `animation-duration: 300ms` を1要素より、`120ms` を10要素＋`animation-delay` で位相をずらす）。
- 1画面の情報量を削って切替点を増やす（1語テロップ、`step-end` の差し替え）。
- 常時ループを入れる場合は duration を 20秒以上に置き、応答系（100〜300ms）と**別の層**として設計する。同じ 150ms に揃えない。

## 反例

- **tinybird**: 宣言ベースの中央値 300ms は NN/g の推奨（単純なマイクロインタラクション 100–150ms）より遅いのに、観察者は「硬質で、押すと即座に沈む」と印象を述べた（**画面は未確認**）。平均が遅くても体感が速い可能性があり、傾向の反例候補。ただし印象は視覚的裏付けを伴わない。
- **gumroad**: 常時ループが 20〜80秒で「短い間隔」ではない。長い帯＋短い応答の併用であり、「短い＝速い」という単純化の反例。一方で「平均は分布を隠す」ことの支持例でもある（同じ観察が両側に効く）。
- **caption**: 教育系・解説系のショートでは 5〜8語ブロックを 100〜140語/分で出す例が実務記事内で推奨されている（記事の記述のみ、測定の開示なし）。「削るほど速い」は成立しない。
- **asl**: 平均 ASL が長い作品でも短ショットの連続で「速い」と評される例（音楽PV・スポーツハイライト）は、数値つきでは**見つからなかった**。

## 強度の分布

- **強い**: caption の1語テロップ（切替 約3回/秒。cps 上限内のまま切替だけが多い）— ただし記事の記述のみで一次計測なし。
- **中**: gumroad（150ms 応答 + 20〜80秒の帯。二層だが層内は単調）。
- **弱い**: tinybird（300ms 単峰。「速い」より「揃っている」側に寄る）。
- **逆**: 静止中心のページ（該当観察なし＝未確認）。

## 反論・保留（2026-11-16 Codex レビュー: 昇格に反対、仮説としての保持に賛成）

- **ASL と「カット数/分」は逆数関係**（60 ÷ ASL）。したがって「平均より切替回数が体感を説明する」の証拠に、同じ区間の回数/分を使うことはできない。**この指摘は正しい。** 本傾向の中心命題は「分布の形（下方テール）」側に置き直す必要がある（本文の(a)は(b)の言い換えになりうる）。
- 「下方テールが中央値を動かす」には、件数が半数をまたぐか等の条件が要る。単に短い値が数件あるだけでは中央値は動かない。
- CSS 宣言の集計と実際の切替頻度は別物。宣言ベースの測定は「設計意図」の観察であって「体感」の証拠ではない。
- 知覚評定は依然是0件。**中心命題（体感を決める）は未支持**。
- 提案: 一般LPから得た仮説をドパガキ固有の規則へ直結させない。実作品の追加調査を優先する。
