# 傾向（patterns）

**複数の観察が同じ徴候を指したとき**に立てる、条件つきの一般化。単一作品の特徴は傾向ではない。

## 立てる条件（[docs/01-method.md](../docs/01-method.md) の G3）

- 3件以上の**独立した**観察が支持している（同じ素材の複数観察は1件と数える）
- **現れる条件**と**現れない条件**が書けている
- 反例が1つ以上ある
- 単一の作品・単一のジャンルへの依存がない（依存するなら「条件」に書く）

## ルール

- ファイル名: `P-<slug>.md`（例: `P-scroll-acceleration.md`）
- `evidence:` に観察IDを列挙（3件以上）
- 実装上の対応物（どのCSS/JS/構成で起きるか）を書く。ここが規則への橋になる
- 強度の分布（強い/弱い事例）を書く。二値にしない

## 書き方

1. 傾向を1文で
2. 現れる条件
3. 現れない条件
4. 実装上の対応物
5. 反例
6. 未検証・次に測る
