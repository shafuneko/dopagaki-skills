# 0001 中央インデックスを持たない

- 状態: 採用
- 日付: 2026-11-16

## 背景

このリポジトリは2つの環境が Syncthing で作業ツリーを共有する。両者が同時に素材や観察を追加する。
当初は `index.tsv` のような中央の台帳を置く案があった。

## 決定

**中央インデックスを持たない。** 索引は各ファイルの front-matter（YAML）から `tools/build-index.mjs` が生成する（`dist/`）。

## 理由

- 2人が同時に1ファイルへ追記すると、Syncthing でも Git でも必ず衝突する。衝突解決のたびに索引の整合性が壊れる。
- 索引は「全部を1か所で見たい」という表示上の要求であって、データの実体ではない。表示は生成で足りる。
- 生成物を Git 管理外にすることで、索引の更新コミットというノイズも消える。

## 帰結

- 新しい素材/観察/傾向/規則は**ファイルを1つ作るだけ**で索引に載る。
- `node tools/build-index.mjs` が参照の整合性（存在しないIDへの参照、ID重複）を検査する。
- 索引が欲しくなったら生成物を見る。手で編集しない。
