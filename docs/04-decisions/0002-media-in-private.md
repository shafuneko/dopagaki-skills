# 0002 第三者のメディアは corpus/private に置く

- 状態: 採用
- 日付: 2026-11-16

## 背景

観察対象は第三者のサイト・動画・スクリーンショットが中心になる。一方でこのリポジトリは GitHub で公開され、Syncthing で同期される。

## 決定

- メディア本体（画像・動画・コードのコピー）は `corpus/private/<slug>/` に置く。**Git 管理外**（`.gitignore`）、Syncthing では同期する。
- Git 管理下には `meta.yml` と `notes.md`（メタ情報・出典URL・短い引用・観察）だけを置く。

## 理由

- 著作権: 第三者の画像・動画を公開リポジトリに置かない。
- 容量: 動画・スクショを Git に入れると履歴が膨らみ、P2P 同期も重くなる。
- 再現性: 出典URLと取得日時があれば、第三者が後から確認できる。

## 帰結

- リポジトリを clone しただけでは素材本体は手に入らない（観察の再現には出典を辿る）。
- `corpus/private/` の中身を要約して Git 管理下に転記することは禁止（[AGENTS.md](../../AGENTS.md)）。
- 自分の作品（`rights: own`）は本体を公開してよい。その場合は `corpus/public/` を使う余地を残す（未実装）。
