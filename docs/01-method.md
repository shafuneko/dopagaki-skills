# 抽出パイプライン — 事例から規則を作る手順

ドパガキに定義はない。だから**演繹しない**。素材を観察し、傾向を数え、規則に昇格させる。以下はその手順とゲート（関所）。

## 全体

```
素材 corpus/items/<slug>/      1件 = 1ディレクトリ（meta.yml + notes.md）
  │  観察する（事実/測定/印象を分離）
  ▼
観察 observations/O-<date>-<slug>.md    1素材1ファイル。徴候に S-1, S-2… と番号
  │  3件以上の観察が同じ徴候を指す
  ▼
傾向 patterns/P-<slug>.md               条件・反例・強度の分布
  │  実装可能な形に翻訳し、2人合意
  ▼
規則 rules/R-<domain>-<slug>.md         命令形1文＋強度(1-5)＋効く条件/効かない条件
  │  タスク向けに再編（コピーしない）
  ▼
スキル skills/dopagaki-frontend/        手順。詳細は references/
  │  ルブリックで検証
  ▼
検証 evals/
```

## ゲート（ここを通らないものは次へ進めない）

| ゲート | 通過条件 |
|---|---|
| G1 素材 | 出典・権利・観察範囲（何を見たか）が `meta.yml` に書かれている |
| G2 観察 | 事実 / 測定 / 印象 / 仮説が節として分離されている。反例または例外が1つ以上ある。数値には測り方がある |
| G3 傾向 | 3件以上の独立した観察が支持。単一作品への依存がない。**現れない条件**が書かれている |
| G4 規則 | 実装可能な形（数値・手段・判断基準）。強度1-5。効く条件と逆効果の条件。根拠ID。2人合意 |
| G5 スキル | 手順として再現可能。ルブリックで採点済み。規則のコピーではなく再編 |

## 抽象語を測れる形に翻訳する

ドパガキの語彙は印象語なので、そのままでは規則にできない。**観察のたびに測定語へ翻訳する。** 翻訳表（随時追記）:

| 印象語 | 測るもの（例） | 単位・尺度 |
|---|---|---|
| うるさい | 色相数、点滅Hz、同時に動く要素数、音イベント数 | 個 / Hz / 個 / 回/分 |
| 速い | `transition-duration` の中央値、カット間隔（ASL） | ms / 秒 |
| チープ | フォント種数、影・グラデの不一致数、画像解像度 | 個 |
| 気持ちいい | 報酬イベントの間隔、予測誤差の大きさ | 秒 / 段階 |
| 酔う | 移動量/秒、視差の層数、全画面トランジションの回数 | px/秒 / 層 / 回 |
| うざい | 自動再生・自動更新の数、閉じられない要素の数 | 個 |

翻訳できない印象は、いったん「未翻訳」として残す（消さない）。翻訳できた時点で axis に紐づける。

## 品質基準（5つ）

1. **遡及可能性** — 規則から素材まで辿れる。辿れない規則は無効。
2. **反証可能性** — 「こうなったらこの規則は間違い」を書ける。
3. **測定可能性** — 数値には測り方（何を・どの範囲で・何回）がある。
4. **条件依存性** — 効く条件と効かない条件が書かれている。万能の規則は存在しない。
5. **強度の明示** — すべての規則に 1-5 の強度。0/1 の二値にしない。

## アンチパターン

- 定義から演繹して規則を作る（「ドパガキとは刺激なので、刺激を増やす」）
- 有名作の見た目をそのまま規則化する（再現手順がない）
- 反例を消す・例外を平均に埋める
- 「良さそう」で昇格する
- 数値を出典も測り方もなく書く
- 1つの作品から一般則を作る（G3 違反）
- 印象を事実の欄に書く

## 観察者バイアスの扱い

- 印象は「主観」節にだけ書く。断定しない。
- 同じ素材を2人が観察したら、徴候の一致率を見る（一致しない徴候は語彙の問題か、見落としか）。
- 「自分が好きな作風」に寄るバイアスを避けるため、**反例（嫌いな作風でも徴候が出る例）**を積極的に集める。
