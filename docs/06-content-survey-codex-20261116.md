# 「ドパガキ」を含むコンテンツの調査

調査日: 2026-11-16。担当: Codex。

## 範囲と確認方法

題名・紹介文・企画のテーマに「ドパガキ」が明示される実作品を検索した。検索語は「ドパガキ 漫画」「ドパガキ ゲーム」「ドパガキ YouTube 切り抜き」「ドパガキ MV」等。用語解説記事そのものは作品一覧に含めない。網羅的な一覧でも人気順でもない。

今回は配信・投稿ページのテキストと作者の制作記事を調査した。ゲームの実プレイ、動画の視聴、楽曲の試聴、漫画画像の通読は実施していない。説明文に記載された仕様と、実際に体験して確かめた挙動を混同しない。数値は特記がない限り配信元の記載値で、独自測定ではない。

検索結果の要約だけで動画の演出を分析しない。再生数や「バズった」という表現を制作効果の証拠にしない。第三者メディアの本体は保存せず、公開ページの要約とURLだけを記録した。素材の再利用条件は別途確認が必要。

## 配信元・投稿元の説明を確認できた作品

### 育てろ！ドパガキ — 育成ゲーム

- 作者・配信元: ArkArtworks CO.,LTD.／App Store。
- 出典: https://apps.apple.com/jp/app/id6802966688 （短縮URLで取得できない場合はApp Store内で作品名・IDを検索）。本文は作品名を含む正式URLから確認。
- 確認箇所: ストアの紹介文。公開日は今回未確認。
- 事実: 日々の行動選択で少年の姿やスキルが変化する育成作品。紹介文には、同じ刺激への慣れ、遊びの切り替え、休息をゲーム内の選択として記載。育てたスキルを使うリズム大会と周回収集も案内されている。
- 数値: 育成期間30日、進化8種類、大会20秒とストアに記載。実プレイでの時間計測や分岐数の検証はしていない。
- 次の観察候補: 行動→成長→外見変化→大会という報酬の段階。休息を選んだ場合の結果表示。
- 反例・限界: 「じっくり挑戦」も用意されているとの説明があり、名称から常時高速操作と推定できない。

### ドパガキ氷つくってみた — ブラウザゲーム

- 制作: ドーパミン水族館（かめこもり／ペギンン／Ask.A）。
- 作品: https://unityroom.com/games/dopagakigoori
- 作者の制作記事: https://note.com/merikongame19/n/n723fbd90008d
- 公開日: 2026-08-05（投稿ページ）。制作記事は2026-08-11。
- 確認箇所: 投稿ページの紹介・クレジット・実況ポリシー、制作記事の企画経緯。
- 事実: かき氷を題材にし、マウス・タップで操作する作品。投稿ページはサムネイル・SNS投稿について別途利用ルールの確認を求めている。
- 作者説明: 制作記事では、題名の言葉遊びから企画が始まり、見せ方と実際の遊びの差を核にしたと説明。詳細はネタバレを含むため、先に作品を体験してから記事を読むことが案内されている。
- 次の観察候補: 導入で生じる期待と後続体験との差、刺激が多い場面と少ない場面の切り替え。
- 反例・限界: 作者は「ゲーム自体はドパガキ向けにしない」とも説明。題名に語を含む作品と、高刺激の提供を目的にした作品は一致しない。記事内の観客像・心理説明は作者の仮説であり、検証済みの心理学的事実ではない。

- 配信元: ひと息パズル。
- 出典: https://asobi.gracetrade.co.jp/dopagaki-check/
- 確認箇所: 「どんなゲーム？」「遊び方」「よくある質問」。公開日は未確認。
- 事実: 切り替わる数字から指定の数字だけに反応する課題に、SNS風通知とボーナスの選択を組み合わせている。結果にタイプとメーターを表示するとの説明。
- 数値: 制限時間60秒、対象数字7と配信元に記載。反応時間等の独自測定はしていない。
- 次の観察候補: 主課題と通知の視覚的な優先順位、誘惑を無視した場合と押した場合の反応の違い。
- 反例・限界: 医学的判定ではなく遊びの診断と明記。結果の数値を実際の集中力・依存状態の測定値として使えない。

### ドパガキ毛抜き — ブラウザゲーム

- 配信元: POCKETFUL。個人作者名・公開日は未確認。
- 出典: https://pocketful.games/g/kenuki/

- 反例・限界: 操作を続けるだけでなく待機を求めるルールがある。高速連打だけを共通特徴とする仮説の反例候補になる。

## 制作のための暫定的な見方

同じ語を使っていても、役割は異なる。上の事例では、育成対象の名前、遊びのテーマ、音楽の制作コンセプト、物語内の能力名、切り抜き動画の題名などに使われている。これは作品説明を整理したもので、演出の共通性を実測した結論ではない。

仮説として調べる価値があるのは、「操作への小さな報酬」「刺激と待機の対比」「期待していた遊びの転換」「短い行動の長期的な積み重ね」。現段階では制作ルールへ昇格させない。

次の実作品観察では、ゲームは同じ操作条件、動画・音楽は固定した時間範囲で観察し、操作から反応までの遅延、演出の変化位置、休止・停止手段等を記録する。測れない印象は主観として残す。題名に語があるだけで高刺激と判定しない。
