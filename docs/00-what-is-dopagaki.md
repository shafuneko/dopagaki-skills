# ドパガキとは何か — そしてこのリポジトリでの扱い

## 1. 語としてのドパガキ

「ドーパミン中毒のガキ」の略。日本語のネットスラングで、短尺動画・SNS・ゲームのような高刺激コンテンツに慣れ、常に強い刺激を求め、集中が続かなくなった若年層を揶揄する語。

- **起源**: 2024年12月28日の X 投稿とされる。Mrs. GREEN APPLE「ライラック」への曲評で、「集中力がないZ世代のガキが途中で再生止めないように一定間隔でメロディに変化を加えてて、ドーパミン中毒のガキ相手の商売って大変だなって思いました」という内容。**原投稿は未取得**（Wikipedia の注記と複数の紹介記事による）。MV・ダンスが起点という説は、確認した資料には見当たらない。
- **拡散**: 朝日新聞（2026-10-02）が X 上の投稿 92万7653件を分析。言及は 2025-03 の 11 件 → 2025-07 の 233 件 → 2026-04 の約 4 万件 → 2026-08 の約 30 万件で、90% が直近 4 か月。大規模アカウント 810 件・186 日を分析した結果、**単一の火付け役が広めたという説明は統計的に支持されない**。2026 年には新語・流行語大賞の候補として報道された（公式のノミネート一覧は未確認）。
- **用法**: 主に3つ。(a) 作品ラベル「〜向け」（例: ドパガキ向け）(b) 自嘲・状態「〜すぎる」(c) 呼びかけ「寝ろドパガキ」。「ドパい」「ドパが効いてる」はドパガキ由来の実例を確認できていない（「ドパい」は英語 dope 由来の別語の可能性がある）。
- **派生語**: ドパ中、アドガキ（アドレナリン中毒のガキ）、ドパ舌、ドパる、ドパオジ。ドパ舌は「濃い味に慣れきった舌」と「刺激に慣れた感覚」で語釈が揺れる。
- **批判**: 医学的診断名ではない（ICD に「ドーパミン依存症」という診断は無い）。高頻度の刺激一般に選択的に当てはめる根拠は薄く、「若者の集中力が壊れた」型の言説は過去にも繰り返されてきた（18世紀の印刷物、2015年の「金魚の9秒」説など）。詳しくは下の出典と [research/20261116-psych-refs.md](../research/20261116-psych-refs.md)。

## 2. このリポジトリでの扱い

対象は**人ではなく、作品の知覚的特徴**。人を分類・評価しない。語の揶揄的な響きは引き継がない。

作業定義（仮）:

> **ドパガキ感** = 短い間隔で強い刺激が連続し、予測を裏切り、即時に報酬を返す表現の総体。

この定義は固定しない。[docs/05-hypotheses.md](05-hypotheses.md) の仮説で検証し、反証が出たら書き換える。定義を先に固めると、定義に合う事例だけを集める循環に陥るため。

### 扱わないこと

- 誰がドパガキか、という人物分類。
- 依存を煽る設計の推奨（刺激の強度と、停止・離脱の自由は別軸として扱う。→ [evals/rubric.md](../evals/rubric.md)）。
- 「若者向けデザイン」一般論への還元。

### よくある誤解

1. **派手ならドパガキ、ではない** — 静けさ・余白は、動との対比で刺激を強める（軸 `restraint`）。
2. **速ければドパガキ、ではない** — 速さは強度の一成分にすぎない（軸 `tempo`）。
3. **刺激は多いほど良い、ではない** — 過剰は「チープ」「不快」に転じる（軸 `backlash`、仮説 H5）。
4. **年齢の話ではない** — 知覚と注意の問題であり、属性ではない。

## 3. このリポジトリが目指すもの

「ドパガキ感を出したい」と思ったときに、

1. どの軸をどれくらい振るかを決められ、
2. 実装の具体（数値・CSS・JS・構成）に落ち、
3. できたものを採点して直せる

状態。そのために、事例 → 観察 → 傾向 → 規則 → スキルのパイプラインを持つ（[docs/01-method.md](01-method.md)）。

## 4. 倫理ライン（骨組み段階の暫定）

- 刺激の強度と、**止められる・減らせる・離脱できる**は別軸。後者を担保しない作品は採用しない。
- WCAG 2.2.2（自動更新の停止手段）、2.3.1（閃光）、1.4.2（自動音声の制御）を満たさないものは、ドパガキ度が高くても不可。
- 詳細は [evals/rubric.md](../evals/rubric.md) の「ゲート」節。
