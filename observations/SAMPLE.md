# 記入例 — ショート動画風の物販LP

## 1. 対象と見た範囲

- 素材: `corpus/items/20261116-demo-shortvideo-lp/`（架空）
- デバイス / 画面幅: デスクトップ 1440px / モバイル 390px
- ブラウザ: Chromium 系
- 見た範囲と時間: 初期表示から3画面スクロール、購入導線のモーダルまで。各2分、計2回

## 2. 事実（測定）

| 指標 | 値 | 測り方 |
|---|---|---|
| `transition-duration` の中央値 | 180ms | DevTools で可視要素30個の computed style を抽出 |
| 5秒あたりの変化回数 | 14回 | 画面録画10秒を0.5秒刻みで目視カウント（2回の平均） |
| 画面内の色相数 | 9 | スクショを減色し、面積1%以上の色相を数える |
| アニメ要素率 | 0.18 | `getAnimations().length / querySelectorAll('*').length` |
| 動画の ASL | 1.2s | ショット検出（PySceneDetect）。中央値 1.0s |
| 音イベント数 | 6回/分 | 効果音の発生を目視・聴取でカウント |
| 停止手段 | なし | 自動再生の停止ボタン、モーダルの閉じるボタンを探索 |

## 3. 徴候

- **S-1**: テロップと商品画像が約1秒間隔で入れ替わり、同じ画面が2秒以上続かない。
- **S-2**: スクロールすると必ず新しいレビュー・バッジ・カウントダウンが現れ、終端がない。
- **S-3**: 音付きの自動再生（ミュート初期状態）＋スクロール同期の効果音。
- **S-4**: 色は原色寄り（赤・黄）で、価格と「今だけ」の文字が画面の3割を占める。
- **S-5**: モーダルの閉じる手段が小さく、背景クリックでは閉じない。

## 4. 印象（主観）

- 「うるさい」「落ち着かない」— 観察者1名。
- 「次が見たくなる」— 同上。刺激と不快が同居している。

## 5. 仮説

- H1（テンポ）・H4（即時性）・H5（反発U字）に関係。速さは快と不快の両方に寄与していそう。
- H6（対比）は不成立: 静区間がまったく無い。

## 6. 反例・例外

- 同じ運営の別ページ（色数3、静止画中心）は `tempo` が同程度でも「うるさくない」と評定された。
  → テンポ単独では「うるさい」を説明できない（`intensity` との交互作用）。
- モーダル内の1画面だけは静止しており、そこで離脱率が下がるかは未計測。

## 7. 未翻訳・次に測る

- 未翻訳: 「チープさ」。バッジの多さか、影の不統一か切り分けられていない。
- 次に測る: スクロール速度を半分にしたときの変化回数、音をミュートしたときの評定差。
