# 観察（observations）

**1素材1ファイル**。素材を見て分かったことを、事実・測定・印象・仮説に分けて書く。
ここが一番大事な層。規則の質は観察の質で決まる。

## ルール

- ファイル名: `O-<YYYYMMDD>-<slug>.md`（例: `O-20261116-scroll-tempo.md`）
- `corpus:` に素材IDを必ず書く（1ファイル1素材。複数素材を見比べた場合は `patterns/` 側で扱う）
- **事実 / 測定 / 印象 / 仮説を節として分離する**。印象を事実の欄に書かない。
- 数値には**測り方**（何を・どの範囲で・何回）を添える。
- **反例・例外を最低1つ**書く。無い場合は「見つからなかった」と書く（探したことを示す）。
- 徴候には `S-1`, `S-2`… と番号を振る。傾向（patterns）はこの番号を参照する。
- 未翻訳の印象は捨てず「未翻訳」節に残す。

## 節の構成

1. 対象と見た範囲
2. 事実（測定）— 表
3. 徴候 — 番号つき
4. 印象（主観）
5. 仮説
6. 反例・例外
7. 未翻訳・次に測る
