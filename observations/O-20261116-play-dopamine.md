# O-20261116-play-dopamine — DopaMINE

## 1 対象と見た範囲

- URL: https://unityroom.com/games/dopamine（Unity / WebGL。第1回 Gamma Game Jam 参加作品、お題「ドパガキ」、製作期間1週間）
- 見た範囲: 作品ページ → ロード中の夜空 → タイトル（ネオン看板「DopaMINE」「ー クリックでスタート ー」）→ 導入演出（赤い歪み文字「投入禁止」「潰しますよ」、紫の光の柱、"Max:5,000,000,000,000"）→ プレイ画面（"20 DP" の通貨バー、SHOP、B1F、作業員スプライト2体）。
- 時間: 15:28–15:38（約10分）。うち**実際に画面が動いていた時間は約15秒**（クリック2回＋待機）。プレイ画面での操作は SHOP クリック1回と坑道クリック1回のみ。
- 端末: Windows / ego lite 0.6.3.14 / Chromium。iframe を直接開いて unityroom のラッパーを外した（キャンバス矩形 `[157.2, 0, 1063, 598]`）。
- 音: ミュートせずに観察したが、**音の有無は判定できなかった**。

## 3 徴候

- S-1: **通貨が最初から画面の主役。** プレイ画面の最上部に "20 DP" のピンクのバーが常設され、画面で最も明るい要素のひとつ。数値が「増える対象」として最初に提示される。
- S-2: **演出で待たせる。** クリック→タイトル→クリック→導入演出→プレイ画面、と**プレイ開始までに2回のクリックと1本の演出**が挟まる。しかも導入演出は赤い文字が歪む凝ったもので、飛ばせない（スキップ操作は見つからなかった）。
- S-3: **巨大な桁の提示。** 導入演出で "Max:5,000,000,000,000"（5兆）を表示する。現在値 20 DP との差が極端で、伸びしろの大きさを数字で見せる演出。
- S-4: **作業員を「こき使う」というコピー。** 紹介文「ドーパミンで動くドパガキ作業員をこき使って」。プレイ画面でも作業員スプライトが坑道に並び、それぞれピンクのバー（進捗）を持つ。
- S-5: **開封演出の予告。** 紹介文「アーティファクトの開封には演出盛り沢山！大量にドーパミンを分泌させ」。ガチャ/開封の演出が報酬の中心に置かれている（本文では未確認）。
- S-6: **ドーパミンを通貨にする。** 紹介文「ドーパミンを通貨として、鉱山やドパガキを強化することができる」。感情の名前をそのまま経済の単位にしている。

## 4 印象（主観）

タイトルのネオンが思ったより静かで、**5秒間まったく動かなかった**のが意外だった（常時アニメを予想していた）。導入演出の赤い文字は不穏で、ゲームの入口としては少し怖い。プレイ画面は暗い坑道で、派手さより「じわじわ増える」感じ。20 DP という小さい数字を見せられた時点で「もっと増やしたい」と思ったのは確かで、数字の置き方としては素直に効いている。

## 5 仮説

- 仮説1: 本作のドパガキ性は**点滅や速度ではなく、演出の密度と数字の設計**にある。タイトルは静止、プレイ画面も暗いが、導入演出と通貨バーで「これから増える」という期待を作っている。
- 仮説2: プレイ中の変化（≒0.9回/0.5秒）は、作業員の歩行・光の粒・ネオンの点滅といった**並列の小さな動き**の合算で、単一の大きな刺激ではない。したがって「画面の変化回数」だけでは刺激の強さを代表できない可能性がある。
- 仮説3: 開始クリックは本作では正常に機能した（タイトル→演出→プレイ画面に遷移）。同環境の dopa-wick で反応しなかったのは作品固有の要因と考えられる。

## 6 反例・例外

- **反例1: タイトル画面が完全に静止している（0回/5秒）。** 「開始前から常時アニメ」というドパガキ的パターンには当てはまらない。doper-duper は 12枚中11枚、dopa-wick は 15点中14点が変化していたのと対照的。
- **反例2: 強い閃光が無い。** 導入演出の赤い歪みは1〜2秒で、1秒3回を超える明滅ではない。プレイ画面も暗色调で、まぶしさは無い。
- **反例3: 停止手段を用意している可能性。** 未測定だが、一般的な unityroom 作品と同様にポーズやタイトルへ戻る手段があるかは確認していない。「停止できない」と断言はできない。

## 7 未翻訳・次に測る

- 開封演出の実測（1回あたりの秒数、点滅回数、スキップ可否、報酬の種類数）。
- 作業員の増加速度と DP の増加レート（DP/秒）、鉱山強化のコスト曲線。
- 停止手段（ポーズ/ミュート/タイトルへ戻る）の有無と位置。
- 音の有無と、開封時に音が鳴るか（実機で聴ける環境で）。
- プレイヤーの操作が実際に DP を増やすのか、放置でも増えるのか（今回は SHOP/坑道を1回ずつクリックしただけで、増加の因果を確認できていない）。
