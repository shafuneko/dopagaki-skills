# 評価（evals）

作ったもの（または他者の作品）を**測る**ための場所。2種類ある。

1. **ゲート**（[rubric.md](rubric.md) の G）— 制御可能性・アクセシビリティ。**合否**。点数より優先。
2. **ルブリック採点** — ドパガキ度を 0〜16点で見る。制作中の自己評価と、作品間の比較に使う。

## 原則

- **点数は観察ではない。** ルブリックの点数を `patterns/` や `rules/` の根拠IDにしない（主観が混ざるため）。根拠にできるのは [observations/](../observations/) の測定。
- AIによる採点は**参考値**として扱う。単独で「ドパガキである」と断定しない。
- 採点者を書く。1回の採点で断言せず、差が大きいときは再協議する（[rubric.md](rubric.md) の「ばらつき」）。
- ルブリックを変えると過去の点数と比較できなくなる。変えたら [chat.txt](../chat.txt) に書き、必要なら旧版を `rubric-YYYYMMDD.md` として残す。

## 使い方

1. [rubric.md](rubric.md) を開く
2. ゲートを先に判定（1つでも落ちたら不可。点数はつけても「参考」扱い）
3. 4項目を採点し、合計と目標強度を比べる
4. 結果と、根拠にした測定値を記録する（制作メモ／コミットメッセージ／必要なら `evals/results/` を作る）

## よくある誤用

- 点を上げるために刺激を足す（ゲートと反発Rを見ずに）。→ 強度は目標から決める
- 別ジャンルの作品と点数だけで比べる（Rubric は「ドパガキ度」であって「良さ」ではない）
- 採点だけして観察を書かない（次に使う人が根拠を辿れない）
