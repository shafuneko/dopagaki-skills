# ルブリック — ドパガキ度と制御可能性

## 1. ゲート G（合否）— 先に判定する

1つでも落ちたら **不可**。点数に関わらず作品として出さない。

| # | 条件 | 判定方法 |
|---|---|---|
| G1 | 5秒を超える移動・点滅・スクロール（パララックス含む）に、一時停止/停止/非表示にする手段がある（WCAG 2.2.2） | 自動再生・無限アニメ・カルーセル・自動スクロールを列挙し、各々に停止手段を探す。**「アニメを減らす設定」は停止手段の代用にならない**（別項目） |
| G1b | 自動で更新される情報（無限フィード、通知、カウントダウン、株価・チャット等）に、頻度の制御または更新停止がある（WCAG 2.2.2 の「自動更新」） | 更新間隔を測る。更新を止められるか／間隔を選べるか |
| G2 | 1秒に3回を超える閃光がない（WCAG 2.3.1）。面積は同時点滅が 341×256 CSS px（≒10度視野の25%）以下、または輝度差10%未満 | 録画で輝度変化を数える。疑わしければフレーム差分。**面積条件も見る**（小さい閃光は回数が多くても対象外） |
| G3 | 音を勝手に鳴らさない。鳴らす場合は (a) 3秒以内に止められる (b) 独立した音量調整がある (c) ミュートでも情報が成立する（WCAG 1.4.2 / Chrome autoplay） | `autoplay` 属性、`AudioContext.state`、ミュート時の情報量、OS音量と独立か |
| G4 | `prefers-reduced-motion: reduce` で動きを減らせる（WCAG 2.3.3 相当。**社内基準**であって合否の法的根拠ではない） | メディアクエリを有効化して再表示し、意味が伝わるか。止まるだけで内容が消えるなら不可 |
| G5 | 本文のコントラスト比 4.5:1 以上、UI 部品・アイコン・フォーカスリング 3:1 以上（WCAG 1.4.3 / 1.4.11） | 動きの中の文字も測定。装飾文字は除外 |
| G6 | キーボードで操作でき、フォーカス位置が見える（WCAG 2.1.1 / 2.4.7） | Tab だけで主要操作を一周する。`outline: none` のままの箇所を探す |

## 2. 採点（各 0〜4点、合計 0〜16）

### A. 濃度（density）

| 点 | 状態 |
|---|---|
| 0 | 単色に近い。要素が少なく、余白が支配的 |
| 1 | 色は2〜3。要素は必要最小限 |
| 2 | 色数4〜6、情報が画面の半分程度 |
| 3 | 色数7以上、装飾・バッジ・文字が重なる |
| 4 | 画面が埋まる。原色・グラデ・ステッカーが同時に存在 |

測り方: スクショの色相数、1画面の要素数・文字数、アニメ要素率。

### B. 速度（pace）

| 点 | 状態 |
|---|---|
| 0 | 3秒以上のホールドが基本。遷移はゆっくり |
| 1 | ホールド2〜3秒。遷移は400ms前後 |
| 2 | ホールド1〜2秒。遷移200〜300ms |
| 3 | 1秒前後で変化。遷移100〜200ms |
| 4 | 1秒未満の変化が連続。待ちが見えない |

測り方: `transition/animation-duration` の中央値、5秒あたりの変化回数、動画の ASL。

### C. 予測不能性（surprise）

| 点 | 状態 |
|---|---|
| 0 | 完全に予測可能。進捗は線形 |
| 1 | 小さな変化はあるが構造は読める |
| 2 | 次に何が出るか一部読めない |
| 3 | フィード/抽選/演出で「次」が読めない |
| 4 | 報酬のタイミングと内容が読めず、止まる理由もない |

測り方: ランダム分岐の数、無限フィードの有無、可変報酬要素、未読/カウントダウン。

### D. 様式の過剰さ（style excess）

| 点 | 状態 |
|---|---|
| 0 | 素朴。1様式を丁寧に |
| 1 | 1様式に少し癖（太字・硬い影など） |
| 2 | 明確な様式（ネオブルータリズム等）を一貫使用 |
| 3 | 複数様式の併用。質感がぶつかる |
| 4 | グリッチ・ステッカー・3D・レトロが同時。統一感より密度 |

測り方: `mix-blend-mode` / `backdrop-filter` / `conic-gradient` の数、フォント種数、枠・影の硬さ。

## 3. 反発リスク R（0〜4、点数に加えない別軸）

| 点 | 状態 |
|---|---|
| 0 | 酔い・読みにくさ・チープさがほぼ無い |
| 1 | 一部に気になる箇所 |
| 2 | 明確に気になるが許容範囲 |
| 3 | 離脱・不快の原因になりうる（酔い、読みにくい、止められない） |
| 4 | 身体的に厳しい（強い前庭刺激、閃光、音の強制） |

**R ≥ 3 のとき**は強度を下げるか、制御手段を足す（R は「強度の代償」）。R を下げてもドパガキ度は下がらないことがある（制御可能性は別軸）。

## 4. 目標強度との対応（目安）

| 目標強度 | 合計点の目安 | R の上限 |
|---|---|---|
| 1 | 3〜5 | 0〜1 |
| 2 | 6〜8 | 1 |
| 3 | 9〜11 | 2 |
| 4 | 12〜14 | 2 |
| 5 | 15〜16 | 3（それ以上は不可） |

合計が目標より**低い** → 軸の選び方か規則の適用不足。**高い** → 反発とゲートを再確認。

## 5. ばらつき

- 採点者は記録する。2人以上で採点した場合、合計差が **2点超** なら判定を話し合う。
- 同じ人が2回採点して差が出たら、測り方を疑う（目視だけで採点していないか）。
- AI採点は参考値。ゲートの判定も、最終的には人間が確認する。
