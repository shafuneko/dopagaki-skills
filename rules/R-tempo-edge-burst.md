# R-tempo-edge-burst — 刺激の増分は区間の端（開始 0〜3秒と終端）に集中させ、端の外では基準点まで落とす

## 規則

刺激量の増分は区間の端（開始 0〜3秒と終端）に集中させ、端の外では直前に置いた低刺激の基準点まで落とす。

## 実装

### 1. 端の前に「基準点」を置く

端の急変は、直前の静けさとの**差**でしか立たない。最初に低刺激の基準点を置き、その後に端を置く。観察例の基準点は、4秒台のショット、無音、静止、ささやく導入。

```html
<section class="calm"><!-- 静止画1枚・テキスト1行・音なし --></section>
<section class="edge"><!-- ここで急変させる --></section>
```

### 2. 開始の端（0〜3秒）

0〜0.8秒に短い切替を置き、0.8秒で一度 duration を伸ばす。これは「フック 0〜3秒」「パターン割り込みは最初の0.8秒以内」という観察の記述に対応する（記事の記述のみ、測定の開示なし）。

```js
const root = document.documentElement;

// 0〜0.8秒: 短い切替で落差を作る
root.style.setProperty('--dur', '100ms');

// 0.8秒: 一度伸ばす（パターン割り込みの窓）
setTimeout(() => root.style.setProperty('--dur', '300ms'), 800);

// 3秒: 端の外。刺激を落として基準点へ戻す
setTimeout(() => {
  root.style.setProperty('--dur', '150ms');
  document.body.classList.add('restraint'); // 静止・低音量の区間
}, 3000);
```

```css
:root { --dur: 150ms; }

/* 端の外は「長いホールド」に落とす。常時ループは 20秒以上の帯へ */
.restraint .ambient {
  animation-duration: 20s;
  animation-iteration-count: infinite; /* 明示する */
}
```

### 3. 局所バースト（全体平均を上げない）

全体の `transition-duration` や平均ショット長を上げるのではなく、**局所区間だけ**に短い切替を集中させる。観察例は 0.58秒のショットが10連発する区間で、作品全体の ASL は 2.4秒 / 2.0秒のまま。区間の長さは観察例で 0.5〜3秒。

```css
/* バースト区間だけ短い duration を当てる（全体の基準は変えない） */
.burst .tick {
  animation: tick 100ms steps(1, end) 10; /* 10連発 */
}
```

### 4. 終端の端（ループ）

`@keyframes` の 0% と 100% を同一フレームにし、`animation-iteration-count: infinite` を明示する。最終フレーム＝最初のフレームで、終端を開始に一致させる。

```css
@keyframes end-to-start {
  0%, 100% { background-position: 0 0; }
  50%      { background-position: var(--shift) 0; }
}

.loop {
  animation: end-to-start 300ms steps(1, end);
  animation-iteration-count: infinite;
}

@media (prefers-reduced-motion: reduce) {
  .loop { animation: none; }
}
```

### 5. 遮断（ピークの直後に落とす）

ピークの直後に音を止め、テキスト1行だけ残す。観察例はドパガキ氷の「完成時に全画面フラッシュと文字演出 → BGM を止めて『本編を開始しますか』」。落差の振幅は「直前の最大値 − 直後の値」で測る（振幅の閾値は未測定）。

## なぜ効くか（仮説）

強い刺激は持続ではなく、**直前の低刺激との差**として知覚される可能性がある（H6 対比仮説）。強く知覚される区間が局所に限定されているほど、全体平均を上げずにピークを作れる（H8 局所バースト仮説）。終端を開始に一致させると「終わった」という予測誤差が消え、再生位置の感覚が失われる（H9。ただし視聴時間への効果の一次データは未確認）。

## 効く条件

- 端の直前に低刺激の基準点がある（静止、無音、4秒台のショット、ささやく導入）。
- 端が画面または音の**全画面・全音量**で起き、サイズの急変が同時に起きる。
- 高密度区間が局所に限定されている（観察例で 0.5〜3秒）。
- 終端を開始に一致させられる構造（ループ可能な尺、最終フレームを最初に合わせられる編集）。
- 停止・ミュート・reduced-motion のゲートを満たしている（端の急変は刺激が強いぶん、止められることが前提）。

## 効かない・逆効果の条件

- **端が存在しない常時ループ**。gumroad の 20〜80秒の帯は端が見えない連続で、落差ではなく持続。端は必須ではない（反例）。
- **基準点がない**。最初から最大音量・最大密度で始まり、その後も同じなら落差は生まれない。
- **尺が長く、端と端の間隔が数分**ある。端の効果が局所に閉じる。
- **端の急変が知覚閾以下**。音量差・輝度差が小さいと落差にならない（閾値は未測定）。
- **端の急変を連続させる**。点滅・フラッシュが1秒に3回を超えると不可（WCAG 2.3.1）。前庭刺激・酔いも出る。
- **読み物・フォーム・購入確定・エラー表示**。端の急変は読解と確認を奪い、離脱につながる（H5 反発U字の右側）。
- **音の自動再生**。音を鳴らすなら操作起点にし、ミュートでも成立させる（ゲート違反）。
- ライラックは王道の反復構成で、冒頭の音響落差だけでは説明できない（反例）。端の落差は**十分条件ではない**。

## 強度の根拠

**2（弱め・暫定）。**

- 根拠の強さ: **low**（`P-edge-burst` の `confidence: low`）。支持する観察は3件だが、すべて二次記述（紹介記事・分析記事・文献値）で、ドパガキ氷の実プレイは0回、音源・MV の実時間視聴もしていない。0.58秒は文献値であり、自分の計測ではない。
- 条件が揃えば効果は強い（`P-edge-burst` の強度分布の「強い」= ドパガキ氷の完成演出。落差の振幅が最大で、光・音・文字の複数チャネルが同時）。ただしその記述も紹介記事由来なので、規則としての効きは2に留める。
- 一次計測（フラッシュ回数・効果音間隔・BGM 停止タイミング、落差の振幅比）が入れば、3〜4へ上げる候補。
- ゲート（停止可能性・閃光・自動音声）を満たすことが前提。`P-stop-ability` は規則ではなくゲートであり、本規則には含めない。
