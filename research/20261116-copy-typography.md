# 煽りコピーとタイポグラフィの「過剰様式」

日本語の Web / 広告で、**文字そのものを刺激にする**作り方の整理。対象は作品の表層設計であり、人や診断の話ではない。法的な判断は個別ケースで変わるため、本稿は**法的助言ではない**（該当しうる、までしか書かない）。

- 最終更新: 2026-11-16
- 読み方: **実証**（一次研究・規格・行政の一次資料がある）/ **通説**（実務で言われるが一次根拠を確認できていない）/ **仮説**（本稿の推測）をラベルする。
- 「効く」は主に注意・記憶・クリックの話。**売上やCVRの因果は扱わない**（測り方が違う）。
- 「過剰様式」= 意味の伝達より**覚醒度**を優先し、文字の形・動き・記号密度・数字で刺激を作る設計。層は **文 / 形 / 時間 / 密度** の4つ。

## 1. 煽り文の型と、景表法・ステマ規制との境界

### 1.1 型と効く理由の所在

| 型 | 例 | 効く理由のラベル | 法務メモ（断定しない） |
|---|---|---|---|
| 緊急性 | 「今すぐ」「本日23:59まで」 | 通説（先延ばし抑制） | 期限に根拠が無い・過ぎても同じ表示なら**おとり広告**や有利誤認に該当しうる |
| 希少性 | 「限定◯個」「残り3点」 | 通説（希少性の法則。一次研究は書籍中心） | 実在庫と違えば**有利誤認**（取引条件）に該当しうる |
| 限定性 | 「あなただけ」「会員限定」 | 通説 | 実際は全員向けなら有利誤认に該当しうる |
| 権威・情報格差 | 「9割が知らない」「業界の常識を覆す」 | 通説（見出しの型としての利用は確認） | 統計の裏付けが無ければ**不実証広告**（景表法7条2項）の対象になりうる |
| 二重価格 | 「通常10,000円 → 今だけ5,000円」 | 通説（アンカリング） | 比較対照価格に**販売実績**が必要。無ければ有利誤認 |
| 否定形 | 「まだ◯◯で消耗しているの？」 | 通説（ネガティブ優位） | 事実でない断罪は信用毀損・優良誤認の論点になりうる |

### 1.2 法の骨格（一次資料で確認できた範囲）

- **景品表示法 5条**: 1号=優良誤認（品質・規格）、2号=有利誤認（価格・取引条件）、3号=おとり広告。故意でなくても規制対象（[有利誤認とは | 消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/advantageous_misidentification)）。
- **二重価格表示**: 比較対照価格に実態が無いと不当表示。「将来の販売価格」を比較対象にする場合は、確実にその価格で販売する計画が必要（[二重価格表示 | 消費者庁](https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/double_price)）。実務では直近8週間の販売実績を目安にする運用が知られるが、**「8週間ルール」は原典の細部を未確認**。
- **ステマ規制（2023-10-01 施行）**: 広告であることを隠した表示が対象。規制されるのは**事業者（広告主）**で、依頼されたインフルエンサー本人ではない（[消費者庁 特設ページ](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing)）。
- **打消し表示**: 小さな「※個人の感想です」で誤認が消えるわけではない。抑制的表示の考え方はガイドライン側で確認する（本稿では未確認）。

### 1.3 実装チェック（コピーを出す前）

1. 数字（◯個・◯%・◯人）の**出典と測った日付**を1行で書けるか。
2. 期限・数量を、在庫/DB/カレンダーと**同じ値**から描画しているか（手書きの「残り3点」は事故る）。
3. 比較対照価格は、実際にその価格で販売した**日付と期間**を言えるか。
4. 「あなただけ」「限定」が、セグメント条件と一致しているか。
5. 広告であることが**画面上で判別できる**か（PR表記・広告表記）。

## 2. 極太・斜体・縁取り・影・多重アウトライン

**効く理由**: 太さ・サイズは視認性に直結する（実証。WCAG の「大きな文字」= 24px 以上 or 18.66px 以上の太字。§7）。縁取り・多層影は背景から分離する装飾として使われるが、**縁取りは字面を痩せさせる**（線が内側に食い込む）ため細い書体では逆効果（通説 + 実装上の事実）。過剰な影が「通販・ゲーム」の符号として信頼度を下げる方向に働くかは**仮説**（印象測定は未実施）。

```css
/* 極太 + 縁取り + 影。線は字面の中心に乗るので、太くすると文字が細る */
.overkill {
  font-weight: 900;
  font-synthesis: none;            /* 偽ボールド/偽斜体を止める */
  -webkit-text-stroke: 2px #111;   /* Baseline 2017 以降 */
  text-shadow: 0 4px 12px rgb(0 0 0 / .45);
}
/* 8方向の影でアウトライン。角が丸くなるので大型見出し向け */
.outline-8 {
  color: #fff;
  text-shadow:
     1px 0 0 #000, -1px 0 0 #000, 0 1px 0 #000, 0 -1px 0 #000,
     1px 1px 0 #000, -1px 1px 0 #000, 1px -1px 0 #000, -1px -1px 0 #000;
}
/* 多重アウトライン。hard shadow をずらして層にする */
.multi-outline {
  color: #fff;
  text-shadow: 2px 2px 0 #ff2d55, 4px 4px 0 #ffd60a, 6px 6px 0 #0a84ff;
}
```

**落とし穴**

- `-webkit-text-stroke` は**塗りと線の重なり順を制御できない**。SVG なら `paint-order: stroke fill` で線を下に回せるが、HTML テキストでは環境差がある。塗りを守りたいなら影方式か SVG テキストにする。
- `background-clip: text` のグラデ文字に `text-shadow` を当てると、**透明な字面の裏**に影が描かれ透ける。`filter: drop-shadow()` か影用の複製レイヤーを使う。
- 和文の `font-style: italic` は**偽斜体（機械的な傾き）**になりやすい。`font-synthesis: none` で止めるか、斜体を持つファミリーだけ使う。
- 縁取り色と塗りのコントラストが 3:1 を切ると、縁取りの意味が消える（§7）。

## 3. 文字の動き（1文字ずつ・揺れ・跳ね・色変化）

**効く理由**: 動きは周辺視野の注意を奪う（通説。motion onset）。「読ませる」より「止まらせる」に効く。テキストアニメーションの**印象**を実験的に調べた研究はあるが（千葉大 OPAC のPDF）、**読解速度・理解度を測ったものではない**。1文字ずつ出すと読む速度を演出側が決めることになり可読性が下がる、という注意は制作記事にもある（通説）。5秒超の自動の動きには停止手段が必要（実証。WCAG 2.2.2）。

```css
.char {
  display: inline-block; opacity: 0;
  transform: translateY(.4em) rotate(-6deg);
  animation: pop .5s cubic-bezier(.2, 1.6, .4, 1) forwards;
  animation-delay: calc(var(--i) * 60ms); /* 文字ごとに index を渡す */
}
@keyframes pop { to { opacity: 1; transform: none; } }
@media (prefers-reduced-motion: reduce) {
  .char { animation: none; opacity: 1; transform: none; }
}
```

- 文字分割は JS で `<span>` に切る。**読み上げ**で不自然にならないよう、視覚層と `aria-label` を分ける。
- ループする揺れ・跳ねは `animation-iteration-count: infinite` にしない。回数か時間で止める。
- 色変化は色だけで意味を運ばない（WCAG 1.4.1 の論点）。

| 演出 | 読みへの影響 | 使うなら |
|---|---|---|
| 1文字ずつ（60–120ms/字） | 全文が出るまで読めない | 見出し1行だけ。本文には使わない |
| 揺れ（±2–4deg, 0.3s） | 注視点が定まらない | ホバー時のみ。常時は避ける |
| 跳ね（translateY 0.2em） | 行ベースラインが崩れる | 1語だけ。行全体は不可 |
| 色変化（グラデ流し） | コントラストが時間で変わる | 最悪色で 4.5:1 を満たす |
| カウントダウン | 桁が変わると幅が跳ねる | `tabular-nums` + 秒単位の更新 |

## 4. 記号・絵文字・約物の密度

- 「！」の連打、「∞」「★」「▶」、半角カナ、小書き文字（ゃ・っ）は、**文字種を増やして視線を散らす**。
- **通説**: 記号密度が高いほど「元気・お得・初心者向け」の印象になり、同時に「雑・信頼できない」の印象も強まる。印象の測定は未実施（**仮説**）。
- **実証（組版）**: 日本語は仮想ボディ（正方形）で組むため、約物は字面が半分しかない。ベタ組のままだと約物の前後が空いて見え、詰め（ツメ）で調整する（[モリサワ note](https://note.morisawa.co.jp/n/n9b07908be089)）。
- **通説**: 半角カナは環境依存文字として避けられてきたが、Web では表示可能。ただし**読み上げ・検索・コピー**で全角と不一致になりやすい。

```css
/* 約物を詰める（フォントが palt を持つ場合） */
.jp-display { font-feature-settings: "palt" 1; letter-spacing: .01em; }
.jp-body { font-variant-east-asian: proportional-width; }
```

- 記号は**画像ではなく文字**で置く（読み上げ・拡大に耐える）。絵文字は `role="img"` + `aria-label`。
- 「★」を箇条書きの代わりに使うなら `list-style` を使い、記号は装飾に留める。
- 半角カナは入力由来の混入を正規化（NFKC）で防ぐ。表示だけ半角にするのは避ける。

## 5. 数字の見せ方（カウントダウン・桁上がり・%）

| 型 | 例 | ラベル | 注意 |
|---|---|---|---|
| カウントダウン | 「あと 02:14:33」 | 通説（緊急性） | 期限の根拠。更新は1秒ごと、読み上げは邪魔しない |
| 桁上がり | 「1,000 → 10,000」 | 通説（達成感） | 桁が増える瞬間に幅が跳ねる |
| %表記 | 「89% が実感」 | 通説 | 分母・調査母数・時期を併記 |
| 累計 | 「累計12万個突破」 | 通説（社会的証明） | 期間と出荷/販売の別を書く |

```css
.timer { font-variant-numeric: tabular-nums; font-feature-settings: "tnum" 1; }
```

- 読み上げは毎秒読ませない。`aria-live="off"` にし、30秒/1分など**節目だけ**通知する。
- 桁上がりの演出は数字の span にだけ `transform: scale()`。行全体を動かさない。
- 期限は**サーバ時刻**基準（端末時計はズレる）。「%」は丸め方（四捨五入/切り捨て）を注記する。

## 6. フォント種数の上限

- **通説（実務）**: 1ページ 2–3 ファミリーまで。それ以上は一貫性が壊れる、という指摘がデザイン実務側にある（[StackExchange の議論](https://graphicdesign.stackexchange.com/questions/87754/is-there-a-general-rule-of-thumb-about-max-of-font-styles-on-a-web-page)、[Learn UI のガイド](https://learnui.design/blog/mobile-desktop-website-font-size-guidelines.html)）。
- **実務の落とし所（仮説）**: 和文1 + 欧文1 + 見出し用1。ウェイトは 400/700/900 の3段まで。**ファミリーを増やすよりウェイトとサイズで差をつける**。
- 和文フォントは1ファイルが重い。`font-display: swap` とサブセット化を併用しないと、FOIT/FOUT で「煽り」より先に空白が見える。
- 「2–3種」に**一次研究の裏付けは無い**。実務者の合意として扱う。

## 7. 可読性の下限（WCAG と日本語）

| 項目 | 下限・目安 | 出典 |
|---|---|---|
| コントラスト（本文） | 4.5:1 以上 | [WCAG 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)（AA） |
| コントラスト（大文字） | 3:1 以上。24px 以上 or 18.66px 以上の太字 | 同上 |
| 文字サイズ変更 | 200% まで拡大でき、横スクロール不要 | [WCAG 1.4.4](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)（AA） |
| 行長 | 80字以内、**CJK は 40字以内** | [WCAG 1.4.8](https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation.html)（AAA） |
| 行間 | 1.5 以上、段落間は行間の1.5倍以上 | 同上（AAA） |
| 両端揃え | しない | 同上（AAA） |
| テキスト間隔 | 行間1.5× / 段落2× / 字間0.12em / 語間0.16em を壊さない | [WCAG 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)（AA） |
| 自動の動き | 5秒超は停止・一時停止・非表示の手段 | [WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)（A） |
| 閃光 | 1秒3回超の閃光を避ける | [WCAG 2.3.1](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)（A） |

**日本語の本文目安（通説）**: 16px 以上、行間 1.6–1.9、行長 30–40字。モリサワの記事では「字間 ベタ〜+5%、行間 160–190%」が読みやすい本文の目安として示されている（[ベタ組とツメ組](https://note.morisawa.co.jp/n/n9b07908be089)）。

**過剰様式との衝突点**

- 縁取り・影は**実効コントラスト**を下げる。文字色と背景色だけで測ると合格でも、影と縁取りを合成した最悪色で不合格になる。
- 1文字ずつ出す演出は**5秒超**なら 2.2.2 の対象。`prefers-reduced-motion` は 2.2.2 の代替にならない（別物）。
- カウントダウンは「自動更新される情報」なので、停止手段か更新頻度の制御が要る。

## 9. まとめ（実装順）

1. **法務**: 数字・期限・比較価格・広告表記を先に固める。演出は後。
2. **可読性**: コントラスト 4.5:1、行長 40字、行間 1.5 を「演出前」に決める。
3. **形**: 縁取りは太い書体にだけ。影は1–2層まで。多重アウトラインは見出し1箇所。
4. **時間**: 1文字ずつは見出しのみ。5秒超の動きには停止手段。`prefers-reduced-motion` を必ず書く。
5. **密度**: 記号は文字で置き、全角/半角を正規化。絵文字にはラベル。
6. **計測**: 演出の有無で**読了率・理解度・CVR**を分けて測る。印象テストと混ぜない。

**未解決**: 日本語広告における煽り文型の効果量、過剰様式と信頼度の関係、半角カナの読み速度への影響。いずれも一次研究が見つかっていない。
