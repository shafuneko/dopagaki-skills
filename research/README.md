# research — 調査メモの置き場

`docs/` は「確定した方針・方法・決定」だけを置く。**調べただけのメモはここに置く**。
（`docs/` の番号を2人で奪い合って衝突するのを避けるため。[ADR 0005](../docs/04-decisions/0005-docs-numbering.md)）

## ルール

- 命名: `research/<YYYYMMDD>-<英小文字スラッグ>.md`
- 索引の対象外（`tools/build-index.mjs` は読まない）。規則の根拠にするときは `observations/` に観察として書き直す。
- **出典URLと「確認できた範囲／未確認」を必ず書く**。数値には測り方（誰が・何を・どう測ったか）を添える。
- 事実 / 他者の解釈 / 自分の推測 を節で分ける。URLの無い記憶は「未確認」と明記する。
- ここに書いたことは規則ではない。規則にするには `patterns/` → `rules/` の順で昇格させる（[docs/01-method.md](../docs/01-method.md)）。
