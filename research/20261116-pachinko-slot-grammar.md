# パチンコ・スロットの液晶演出の文法 — Web フロントエンド演出への移植のための整理

- 日付: 2026-11-16
- 種別: 調査メモ（確定方針ではない。用語の確認と、Web への移植仮説の材料）
- 目的: パチンコ・パチスロの液晶演出を「段階構造」「用語」「期待度の表現」「派手さの手段」「スロット固有の文法」に分解し、Web のフロントエンド演出に置き換えるための対応表を作る。「ドパガキ演出」の語彙と段階構造を裏付ける。
- 既存ファイルは変更していない（新規1ファイルのみ）

## 0. 出典の質の表記ルール

本文では、記述の確度を次のラベルで示す。

- 【一次】メーカー公式・法令・特許など、発信元が当事者の資料
- 【二次】用語解説サイト・業界メディア・百科事典など、一次資料を要約・再構成した資料
- 【推測】取得した資料から筆者が組み立てた解釈。事実ではない
- 【未確認】業界で一般に言われていても、本調査で裏付け資料を取得できなかったもの

本資料は**事実節（1〜6）と解釈節（7〜8）を分ける**。事実節でも、複数機種に一般化できる保証はない。パチンコ・パチスロの演出名称と意味は機種ごとに大きく異なるため、「一般にこう呼ばれる」以上の断定は避ける。

## 1. 前提: 演出は何を伝えているのか

パチンコの液晶演出は、抽選結果そのものではなく、**すでに内部で決まっている抽選結果を、どの強さ・どの順序で見せるか**を制御している。これは複数の用語解説で繰り返し注意されている点で、本資料の全体を貫く前提になる。

- 信頼度は「その演出が出たときに大当りする割合」であり、**演出の発生によって抽選確率が変わるわけではない**（【二次】ppps 信頼度ページ）。
- 保留の数や保留変化が、大当り確率を後から書き換えるわけではない（【二次】ppps 保留ページ）。
- 先読みは「未来の抽選を予知する仕組み」ではなく、入賞時に記憶した保留情報を使って、対象変動の開始前に事前判定し、演出を選ぶ構成（【二次】ppps 先読みページ。実装例として公開特許 JP2024083668A を挙げる）。

つまり演出の文法は、**結果の隠蔽と開示の順序設計**である。Web に移植するときも、この「結果は先に決まっていて、見せ方だけを段階化する」という構造をそのまま持ってこられるかが要点になる。

## 2. 演出の段階構造

### 2.1 一般に言われる順序

パチンコの 1 変動は、おおむね次の順で進む。これは用語解説の定義を並べた**整理であって、公式の標準モデルではない**（【推測】を含む）。

1. **通常時（非リーチ）**: 図柄が順に止まり、リーチにならずにハズレる。背景・キャラの会話などで状態を示す。
2. **予告**: リーチや当否に向けた前段階の演出。ステップアップ予告、群予告、カットインなどがここに入る（【二次】ppps 用語集）。
3. **リーチ**: あと一つ所定図柄が止まれば揃う状態。ノーマルリーチは発展せず図柄変動が中心（【二次】ppps 用語集）。
4. **発展**: 予告やリーチから、別の演出・上位のリーチへ移行する流れ。スーパーリーチ、SPリーチなど（【二次】ppps 用語集）。
5. **当落演出**: リーチ終盤で、大当りかハズレかの最終結果を見せる総称。ボタンやレバーを押させる機種がある（【二次】ppps 用語集）。
6. **大当り**: 図柄が揃い、大当りラウンド・出玉・状態移行へ。
7. **確変 / ST / RUSH / 時短**: 大当り後の状態。確変は大当り確率が通常時より高くなる状態、時短は電サポで始動口に入賞しやすくする状態で、両者は別概念（【二次】ppps 用語集）。

### 2.2 構造としての特徴

- **段階は入れ子になる**。予告→リーチ→発展→当落、の各段階にさらに予告が挟まる。発展は一方向ではなく、下位リーチから上位リーチへ、さらに別系統へ分岐する。
- **段階の途中で「強い／弱い」の信号が何度も差し込まれる**。これがチャンスアップで、色・文字・カットイン・背景などが変化して期待度が上がる（【二次】ppps 用語集）。
- **段階を飛ばす・崩すことが演出になる**。法則崩れは、想定される組み合わせや発展法則から外れることで、大当り濃厚などの意味を持つ場合がある（【二次】ppps 用語集）。
- **段階の外側に「状態」がある**。確変・ST・RUSH・時短は変動の外側にあり、演出の意味を変える。同じ演出名でも通常時と RUSH 中では期待度が変わるとされる（【二次】ppps 信頼度ページ）。

### 2.3 スロット側の対応構造

スロットは「図柄変動」ではなく「リールの停止」が基本単位になる。

1. **レバーオン**: 回転開始。ここで告知する方式を先告知と呼ぶ（【二次】Wikipedia パチスロ用語の一覧）。
2. **リール回転**: 第1→第2→第3停止へ。
3. **テンパイ**: 2つのリールを押した時点で同一図柄が当選ライン上に並ぶこと。パチンコの「リーチ」に同じ（【二次】Wikipedia）。テンパイ自体は頻繁に発生するため、特定条件下でのみチャンス目・リーチ目として意味を持つ。
4. **揃う / ハズれる**: 3つ目の停止で確定。揃わなければハズレ。
5. **ボーナス・AT・ART の消化**: AT は押し順ナビなどで小役獲得を補助するチャンスタイム、ART は AT に RT を加えたもの（【二次】Wikipedia）。
6. **上乗せ・ループ**: 消化中に同一フラグを引くと残り G 数やセット数が加算される。例として ART 初期 30G 消化中に +50G で合計 80G になる、という説明がある（【二次】Wikipedia）。

## 3. 用語を「何が起きるか / 何を予告するか」で整理

以下は用語解説サイトの定義を要約したもの（【二次】ppps 用語集および各用語ページ）。「何を予告するか」の列は、定義から読み取れる範囲と【推測】を混ぜているため、断定は避ける。

| 用語 | 何が起きるか | 何を予告するか |
| --- | --- | --- |
| 予告 | リーチ前・当否前に、通常と違う演出が入る | これからリーチ・発展・大当りがあること |
| 先読み | まだ消化していない保留について、変動開始前に期待度を示す | 後の保留の変動の期待度・発展先 |
| 保留 | 始動口入賞時の抽選情報を、消化順に待たせる | （予告ではない）消化順の管理 |
| 保留変化 | 保留アイコンの色・形が変わる | その保留の期待度 |
| 先バレ | 入賞直後など早い段階で、音・光で知らせる | 対象保留への期待（先読みの一形態） |
| カットイン | リーチ中などにキャラ画像や文字が挿入される | 発展・当落への期待。色や大きさがチャンスアップになる |
| 図柄変動 | 3つの図柄が順に回転・停止する | （演出の土台）停止形がリーチ・ハズレを示す |
| リーチ | あと一つで揃う形で止まる | 大当りの可能性 |
| テンパイ | リーチ成立条件を満たして残りを待つ状態 | リーチと同じ（スロットでは 2 リール停止時） |
| 発展 | 別の演出・上位リーチへ移る | 期待度の上昇、上位リーチへの移行 |
| 全回転 | 大当りの組み合わせが揃ったまま、複数列の図柄が同期して回る | 大当り濃厚（機種により恩恵の範囲が違う） |
| 復活演出 | いったんハズレたように見せて、そこから大当りに転じる | 逆転当選 |
| フリーズ演出 | 液晶や演出が一瞬止まったように見える | 直後の展開・大当りへの強い期待 |
| レバブル | レバーやハンドルが振動する | 期待度（カスタムで頻度が変わる） |
| 一発告知 | 音・ランプ・ボイスで大当りを知らせる | 当落そのもの（即時告知） |
| 群予告 | 多数のキャラ・図柄が群れで通過・出現する | リーチ・発展への期待 |
| ステップアップ予告 | 段階を追って演出が進む | 段階の深さに応じた期待度 |
| 疑似連 | 1 回の変動中に、複数回変動したように見せる | 連続する変動に見せる（先読みとは別） |
| ゾーン演出 | 特定名称の演出状態に入り、滞在中の期待度を示す | 状態滞在による期待度 |
| 法則崩れ | 想定される組み合わせ・発展法則から外れる | 大当り濃厚などの強い示唆 |

### 3.1 全回転と復活演出の位置づけ

全回転は「大当りの組み合わせが揃った状態を保ちながら複数列の図柄が同期して動く」特別なリーチ演出で、現代的には大当り濃厚のプレミア級とされる（【二次】ppps 全回転ページ）。ただし**「大当り濃厚」と「RUSH・確変まで確定」は別**で、恩恵の範囲は機種による。同ページは、SANKYO「フィーバー花月」では全回転で次回大当りも確定、別機種では全回転で出玉＋ST 突入濃厚、といった差を挙げている。

復活演出は、いったんハズレたように見せてから逆転して大当りにする見せ方で、全回転とは別の軸（【二次】ppps 全回転ページ）。再抽選・図柄昇格も、大当り表示後の見せ方であり、全回転とは区別される。

### 3.2 保留と先読みの関係

保留は「始動口入賞の未消化変動・抽選情報を順番待ちとして記憶する仕組み」で、基本は最大 4 個の機種が多いが、通常時 8 個の機種もある（【二次】ppps 保留ページ、SANKYO 公式案内の引用）。特図 1 と特図 2 で別管理される。

先読みは「まだ変動開始していない保留について、後の大当り期待度や展開を前もって示唆する予告」で、代表例は保留変化・チャンス目・特殊ゾーン・カウントダウン・入賞時フラッシュ（【二次】ppps 先読みページ）。**保留変化は先読みの代表例の一つ**であり、先読みが保留変化より広い概念になる。ただし保留変化が当該変動に入ってから起きる場合は、厳密には先読みとタイミングが違う。

先読みが出ても大当りは約束されない。カスタム「なし／チャンス／熱」で出現頻度と発生時期待度のバランスが変わるが、**カスタムは大当り確率を上げる機能ではない**（【二次】ppps 先読みページ）。

## 4. 期待度と演出の強さ

### 4.1 信頼度の読み方

信頼度は「特定の演出が発生した場合に大当りする割合・期待の水準」で、パチンコ演出の文脈では「期待度」とほぼ同義に使われる（【二次】ppps 信頼度ページ）。重要なのは次の区別。

- **信頼度**: その演出が出たときに当たる割合（条件付き割合）
- **大当り確率**: その遊技状態の抽選で当たる確率（スペック）
- **大当り占有率**: 大当りしたうち、その演出を伴った割合
- **出現率**: 対象変動に対して演出が発生する頻度

信頼度 50% と大当り占有率 80% は両立する。「当たるときの何割で鳴るか」と「鳴ったときに何割当たるか」は別の問いである（【二次】ppps 信頼度ページ）。

また、**複数の演出の信頼度は足し算できない**。赤保留 60% ＋ チャンスアップ 50% ≠ 110% であり、かけ算や単純平均でも正しい合算値は出せない（【二次】ppps 信頼度ページ）。同じ演出名でも、発生順・組み合わせ・発展先・遊技状態で期待度が変わる。

### 4.2 「激アツ」「大当り濃厚」「確定」の扱い

- **激アツ**: 一般に期待度の高い演出を表す言葉。全機種共通の固定 % でも、必ず当たる意味でもない（【二次】ppps 信頼度ページ）。
- **大当り濃厚**: 大当りを非常に強く示唆する表現。メーカー・媒体が「確定」を避けて用いることがある。「80%」「100%」と機械的に置き換えない（【二次】ppps 信頼度ページ、用語集）。
- **プレミア演出**: 発生頻度が低く、大当り濃厚級とされる演出。出現率の低さと大当り保証は同一視できない（【二次】ppps 用語集・信頼度ページ）。
- **星表示**: 期待度を ★5 段階で示す例があるが、★4 を自動的に 80% と換算できない（【二次】ppps 信頼度ページ、SANKYO 公式 Q&A の引用）。

### 4.3 数値の例（1 機種のみ。一般化不可）

業界メディア「dechau! PLUS」の機種特集に、テンパイ図柄ごとの信頼度が掲載されている（【二次】dechau! PLUS、対象は「eフィーバーブルーロック」）。

| 項目 | 信頼度 |
| --- | --- |
| テンパイ図柄 1 | 約 2.6% |
| テンパイ図柄 2 | 約 2.9% |
| テンパイ図柄 3 | 約 79.6% |
| テンパイ図柄 4 | 約 2.7% |
| テンパイ図柄 5 | 約 2.5% |
| テンパイ図柄 6 | 約 66.6% |
| テンパイ図柄 7 | 大当り濃厚 |
| リーチライン 通常 | 約 2.7% |
| リーチライン 赤「チャンスだ！」 | 約 52.7% |
| リーチライン 虹「エゴい！エゴい！」 | 大当り濃厚 |

これは**特定機種の、特定条件での値**であり、他機種に一般化できない。数値を引用するときは、機種名・型式・状態・単体か組み合わせか・カスタム設定・「約」の有無・出典を揃える必要がある（【二次】ppps 信頼度ページ）。

## 5. 派手さの表現手段

### 5.1 用語として確認できるもの

- **虹色（レインボー）**: リーチラインや保留の色として、最上位の期待度を示す演出に使われる例がある（【二次】dechau! PLUS の機種特集、ppps 用語集のチャンスアップ記述）。色の序列は全メーカー共通ではなく、SANKYO 公式は基本を青＜緑＜赤としつつ、虹・金などが上位に置かれることが多い（【二次】ppps 保留ページ、補助として amuse-p の解説）。
- **フリーズ**: 液晶や演出が一瞬止まったように見せる。停止そのものが「何か来る」という信号になる（【二次】ppps 用語集）。
- **レバブル**: レバーやハンドルが振動する。カスタムで発生頻度と期待度が変わる（【二次】ppps 用語集・信頼度ページ）。
- **一発告知**: 音・ランプ・ボイスで大当りを知らせる。即時性が強く、段階を飛ばす（【二次】ppps 用語集）。
- **カットイン**: リーチ中にキャラ画像や文字を挿入する。色・大きさ・内容がチャンスアップになる（【二次】ppps 用語集）。
- **チャンスアップ**: 色・文字・カットイン・背景などが変化して期待度が上がる要素（【二次】ppps 用語集）。
- **群予告**: 多数のキャラ・図柄が群れで通過・出現する（【二次】ppps 用語集）。
- **違和感演出**: 普段と少し違う音・表示・ランプ・タイミングで、変化に気づかせる（【二次】ppps 用語集）。

### 5.2 用語としては未確認のもの

以下は、実機で見られる映像文法としては広く知られているが、**パチンコ業界の標準用語としての名称は本調査では確認できなかった**（【未確認】）。

- 白フラッシュ（画面全体を白く飛ばす）
- 集中線（視線を中央に集める放射状の線）
- 画面分割（複数視点の同時表示）
- 3D 回転（図柄・背景を立体的に回転させる）
- ボタン・レバーの連打要求
- BGM の変化（曲の切り替え・停止・速度変化）
- 声（キャラクターボイス）の追加
- 効果音の重ね（複数 SE の同時再生）

これらは「業界用語」ではなく「映像一般の語彙」として扱うのが安全である。実際、カットインやチャンスアップの定義には「色・文字・背景の変化」までしか書かれておらず、フラッシュや集中線を名指しする資料は見つからなかった。Web に移植する際は、パチンコ用語としてではなく**汎用の演出プリミティブ**として整理したほうがよい（【推測】）。

## 6. スロット側の文法

### 6.1 リールとテンパイ

スロットの基本単位はリールの停止である。テンパイは「2 つのリールを押した時点で同一図柄が当選ライン上に並ぶこと」で、パチンコのリーチに相当する（【二次】Wikipedia パチスロ用語の一覧）。2 種類並べばダブルテンパイ、3 種類ならトリプルテンパイ。テンパイ自体は頻繁に発生するので、特定条件下でのみチャンス目・リーチ目として意味を持つ。

### 6.2 告知のタイミング

- **先告知**: 完全告知機で、レバーオン時・リール始動時に告知する。ジャグラーでは「先ペカり」と呼ばれる（【二次】Wikipedia）。
- **遅れ**: リール回転開始のスタート音が通常より遅れる。ボーナス・小役示唆（【二次】Wikipedia）。
- **リーチ目**: 小役ハズレなどで成立を示す出目（【二次】Wikipedia）。
- **告知の区分**: 完全告知 / 一部告知 / 非告知（【二次】Wikipedia）。

### 6.3 G 数・AT・フェーズ

- **AT（アシストタイム）**: 押し順ナビなどで小役獲得を補助するチャンスタイム（【二次】Wikipedia）。
- **ART**: AT に RT（リプレイタイム）を加えたもの（【二次】Wikipedia）。
- **G 数**: 残りゲーム数。AT/ART の消化単位。
- **上乗せ**: AT/RT/ART 消化中に同一フラグを引くと、残り G 数やセット数が加算される（【二次】Wikipedia、ダイナム用語集）。
- **ループ**: 上乗せが成功するたびに追加が続く仕組み（上乗せループ）。パチンコの確変ループに対応する考え方（【二次】ppps 用語集の上乗せループ記述）。
- **フェーズ**: 演出の段階を「第1フェーズ」「第2フェーズ」のように呼ぶ用法があるが、**業界標準の定義は確認できなかった**（【未確認】）。文脈としては「CZ（チャンスゾーン）→ AT」のような段階移行を指すことが多い、というのが実機観察からの印象（【推測】）。

### 6.4 パチンコとの違い

- パチンコは「変動→リーチ→当落」の 1 回完結が基本単位で、保留で先の変動を予告できる。
- スロットは「レバーオン→3 リール停止」が 1 回の完結で、テンパイは途中経過にすぎない。
- スロットは G 数・セット数という**連続量**を持ち、上乗せ・ループで報酬が積み上がる。パチンコは確変・ST・RUSH という**状態**で連チャンを表現する。
- どちらも「結果は先に決まっていて、見せ方だけを段階化する」点は同じ（【推測】）。

## 7. 解釈: 抽出できる文法

ここからは筆者の解釈であり、事実ではない。

1. **期待度は「単調増加」ではなく「階段＋揺り戻し」**。段階が上がるほど強いが、途中で弱い演出に戻ることで、上がり続けるより強い不安と期待を作る。法則崩れはこの揺り戻しを逆手に取る。
2. **信号は多重化される**。色・音・振動・カットイン・背景が同時に、しかし独立に変化する。1 つの信号だけでは確定しないから、複数の信号の一致・不一致が読みの対象になる。
3. **「確定」を言わない**。大当り濃厚・激アツ・プレミアという語は、確定より弱い。この曖昧さが、外れたときの納得感と、当たったときの特別感の両方を支える。
4. **状態が意味を変える**。同じ演出でも通常時と RUSH 中では期待度が違う。文脈（状態）が記号の意味を決める。
5. **報酬は多層**。当落→出玉→確変/ST/RUSH→上乗せ・ループ、と報酬の単位が入れ子になる。1 回の当りで終わらず、次の報酬への入口が開く。

## 8. Web フロントエンド演出への対応表

以下は【推測】。パチンコ・スロットの語彙を、Web の実装要素に置き換えるための作業仮説。

| パチンコ・スロットの用語 | 何をしているか | Web での実装要素（仮） |
| --- | --- | --- |
| 保留 | 未消化の抽選情報を順番待ちにする | キューのデータ構造。`queue` / 配列 + 状態機械 |
| 先読み | 消化前の保留について期待度を先に示す | 演出の事前シグナル。`prefetch` 的な先出しアニメ、`data-` 属性での前兆フラグ |
| 保留変化 | 保留アイコンの色・形が変わる | リスト項目の状態クラス変更。色・アイコン・バッジの差し替え |
| 予告 | 本編前に短い演出を挟む | インタースティシャルなアニメーション。`animationend` で次段階へ |
| カットイン | 本編に画像・文字を差し込む | オーバーレイ要素の一時挿入。`position: absolute` + 短い `transition` |
| チャンスアップ | 色・文字・背景を変化させる | CSS カスタムプロパティの切り替え。`filter` / `background` のトランジション |
| リーチ | あと一つで揃う状態を見せる | 進捗バーが残り 1 で停止。`progress` の 90% 停止など |
| 発展 | 別の演出・上位段階へ移る | ルーター的な段階遷移。状態機械の `next()` |
| 当落演出 | 最終結果を見せる | 最終判定の表示。`await` の解決後に結果を描画 |
| 全回転 | 揃ったまま同期して回る | 複数要素の同期アニメーション。`requestAnimationFrame` + 共通クロック |
| 復活演出 | ハズレに見せて逆転する | 一度「失敗」状態を描画し、遅延後に成功へ書き換える |
| フリーズ | 一瞬止める | `animation-play-state: paused` の一時停止、または空白フレーム |
| レバブル | 物理的な振動で期待度を示す | `navigator.vibrate()`（対応端末のみ）、または UI のシェイク |
| 一発告知 | 段階を飛ばして即時告知 | 即時のトースト・モーダル・サウンド。段階遷移をスキップ |
| 群予告 | 多数の要素が一斉に現れる | パーティクル的な大量要素の一斉アニメーション |
| ステップアップ | 段階を追って進む | ステップ配列 + 順次 `await`。進捗の可視化 |
| 疑似連 | 1 回の変動を複数回に見せる | 同一処理の再実行に見せる。カウンタのリセット演出 |
| ゾーン | 特定状態に滞在させる | セクション / モード。`data-state` で滞在中の期待度を表現 |
| 法則崩れ | 想定外の組み合わせを作る | 通常の遷移規則を意図的に破る分岐。例外パスの明示 |
| 確変・ST・RUSH | 高確率・連チャンの状態 | セッション状態。`state = 'rush'` のようなモード |
| 上乗せ | 確定報酬に追加する | スコア・残量への加算。ボーナスの積み上げ |
| ループ | 成功のたびに追加が続く | 再帰的な報酬処理。上限付きの `while` |

### 8.1 移植時の注意

- **「結果は先に決まっている」構造を保つ**。Web でも、抽選（乱数）→ 結果確定 → 演出選択、の順にすると、演出が結果を左右しない設計になる。逆にすると、演出の途中で結果を書き換える実装になり、信頼度の意味が壊れる。
- **信号を多重化する**。色だけ、音だけに頼らず、複数のチャネルを独立に変える。ただし、すべてを同時に最大にすると強度の差がつかない。
- **「確定」を避ける語彙を持つ**。`大当り濃厚` に相当する表現を、`確定` と分けて持つ。Web のコピーでも「可能性が高い」と「確定」を混ぜない。
- **状態が記号の意味を変える**。同じアニメーションでも、`data-state` によって期待度の重みを変える。

## 9. 規制と射幸心について（事実と注意）

パチンコ・パチスロは風営法の規制下にあり、「著しく射幸心をそそるおそれのある遊技機を設置して営業してはならない」と定められている（【一次】セガサミーホールディングス IR コラム）。同コラムによれば、規則によりパチンコの消費金額は 1 分間で 400 円を超えてはならず、1 玉 4 円として 1 分 100 玉が上限、技術上の規格では「1 分間に 100 個を超える球を発射できないもの」と定義される。6.5 号機では有利区間のゲーム数上限が 4,000G に増え、スマートパチスロでは上限が撤廃、枚数上限は MY から差枚管理へ変更された（2,400 枚は変更なし）。

**演出と賭博性は別問題**である。演出の派手さ・段階構造は、射幸心をそそる要素の一部ではありうるが、演出の強さと賭博性は同じものではない。Web に移植する場合も、演出の文法を借りることと、賭博的な報酬設計を持ち込むことは分けて考える必要がある。

景品表示法は、景品・表示の適正化を目的とする法律で、**演出の派手さ自体を直接規制するものではない**（本調査では条文・個別運用を確認していない。【未確認】）。Web の演出に移植する際に参照するなら、景品表示法よりも、アクセシビリティ（点滅・音・動きの抑制）や、依存性への配慮のほうが直接的に関係する。

## 11. ドパガキ演出への含意

1. **期待感は段階的に上げる**。一度に最大まで上げず、予告→リーチ→発展→当落のように段階を刻む。各段階に「まだ上がある」余白を残す。
2. **段階の途中に揺り戻しを入れる**。強い演出の後にあえて弱い演出を挟むと、次の上昇が効く。法則崩れはその極端な形。
3. **当落の不確実性を消さない**。「確定」と言わず「濃厚」「激アツ」に留めることで、外れても物語が壊れず、当たったときの報酬が強くなる。
4. **信号を多重化する**。色・音・動き・文言を独立に変え、視聴者が「どれが効いたか」を読めるようにする。1 つの信号だけに頼ると、強弱の設計ができない。
5. **報酬を多層化する**。当落→出玉→状態→上乗せ、と報酬の単位を入れ子にすると、1 回の当りが次の入口になる。Web では、成功→次のステップの解放、のように置き換えられる。
6. **状態が意味を変える**。同じ演出でも、通常時と高確率状態では重みを変える。`data-state` のような文脈を演出の入力にする。
7. **演出と賭博性は別問題**。段階構造や期待度の文法は、演出論として移植できる。賭博的な報酬設計とは切り離して扱う。
