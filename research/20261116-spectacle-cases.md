## 2. 事例1: DOPA PONG（60 秒 CPU 対戦）
**① URL**: <https://dopa-pong.vercel.app/>
**② 見えるもの（取得テキストの事実）**: 見出しは「DOPA PONG — 60秒、限界のその先へ。」「ONE BALL. ALL THE CHAOS.」。
スコアボードは `SCORE` / `COMBO 00 HITS` / `MULTIPLIER ×1` / `TIME LEFT 60 s` / `PERSONAL BEST` の 5 項目。
下部に **DOPA SLOT**（`0 / 100 抽選 0件`、`CHARGE & SPIN`「返球でためて、100ptで自動抽選」、
`ACTIVE / 装備なし`、`NEXT 0 ストックなし`）。
**FEVER LEVEL** は `0 / 30 HITS` の進捗バーで、5 段階のラダーが常時表示される:

| 段階 | 倍率 | 条件 |
|---|---|---|
| NORMAL | ×1 | 0–4 COMBO |
| HYPE | ×2 | 5–9 COMBO |
| FEVER | ×5 | 10–19 COMBO |
| OVERDRIVE | ×20 | 20–29 COMBO |
| DOPA MAX | ×100 | 30+ COMBO |

起動時に **SUPER DOPA モードの確認ダイアログ**が出る（取得テキストに全文あり）:
「SUPER DOPAモードをオンにしますか？ / 虹色の残像や爆発で、試合の演出が派手になります。 /
注意：強い光や揺れにより、画面酔いや発作などが起きるおそれがあります。端末によっては動作が重くなります。 /
あとからゲーム設定で切り替えられます。」`PERFECT!` で「ボーナス ×3」、`ESC` でポーズ。

**③ 段階構造**: ①起動 → SUPER DOPA の可否（**演出の強度を最初にユーザーへ委ねる**）
②ラリー（コンボ蓄積）→ 5 段階の FEVER LEVEL ③DOPA SLOT ゲージ 0→100 → 自動抽選 → 当選で即発動 /
使用中はストック ④60 秒終了 → スコア。倍率の刻みは **×1 → ×2 → ×5 → ×20 → ×100** で、
等差でも等比でもなく**段階が上がるほど跳ね方が大きい**（1→2 は +1、20→100 は +80）。
**④ 技法**: 虹色の残像 / 爆発 / 揺れ（ダイアログの警告文が根拠）/ 常時見える段階ラダー /
ポイント抽選（0-100）/ ストック表示（NEXT）/ 倍率の非線形ジャンプ / 光過敏への警告文。
**⑤ 出典**: 【一次/取得】ページ本文（HTTP 200）。`index.html` は 404 で SPA ルートのみ。
**未確認**: 依頼メモの `LIMITERS OFF`、ポーズ画面の「TAKE A BREATHER / ひと息ついたら、もう一度。」は
取得テキストに現れなかった（動的表示と推測）。虹色残像・爆発の描画も未確認。

## 5. 事例4: ドパガキ度チェック（60 秒・対象数字 7）
**① URL**: <https://asobi.gracetrade.co.jp/dopagaki-check/>
**② 見えるもの**: 「次々に切り替わる数字の中から『7』のときだけボタンを押す、60秒の集中力テスト」。
「はじめる」→ **3 秒のカウントダウン** → 数字表示。正解 +10 点、7 以外で押すと −5 点。
割り込みは「いいねが99件」「ライブ配信中」などの通知と **「一か八か！±15点」** ボタン。
「後半ほど数字の切り替わりが速くなります」。結果はタイプ + **3 つのメーター**、称号「ひと息職人（極）」。
「『1』と『4』は7に見間違えやすい」「通知は見なくても点数は減りません」。注記「医学的な判定ではありません」。
**③ 段階構造**: カウントダウン（3 秒）→ 本編（数字の切替、**後半で加速**）→ 割り込み（誘惑 UI）→
結果（3 メーター）。強度の源は色ではなく**時間圧（加速）と誘惑の同時提示**。
**④ 技法**: カウントダウン / 数字の高速切替 / 似た字形による誤認誘発（1・4 と 7）/ 通知という
「別の刺激」の重ね置き / ギャンブルボタン（±15 点の一発逆転）/ 結果のメーター化。
**⑤ 出典**: 【一次/取得】ページ本文（HTTP 200）。運営は GRACE 貿易株式会社。

## 6. 事例5: ドパガキ毛抜き（POCKETFUL）
**① URL**: <https://pocketful.games/g/kenuki/>
**② 見えるもの**: 「目覚ましまでの100秒、パパのヒゲを抜きまくれ」、`13:13:20のこり 42本` `あと 100秒` `0 ドパ`。
操作は `うごかす` / `つまむ` の 2 つ。`押せ！` `タップでとばす`。
**ねむりの深さ**が 3 段階で表示: `ぐっすり` / `すやすや` / `うとうと`。注釈より:
- いびきの間（口が大きく開いて Z がふくらむ間）に抜くと起きにくく、**ドパも 2 倍**
- ミスが続くとパパが起きて終了（**ぐっすり 5 回 / すやすや 3 回 / うとうと 2 回**）
- 毛根ごと抜けば 0 に戻る / まぶたがぴくぴくしたら「うす目」の前ぶれ → 手を止める
- **ピンクに光るチャンス毛は 4 秒以内**に抜くと赤以上の保留 / 白い毛根ごと抜けるとうれしい
- PC は `Esc` で一時停止。ポーズは **「ひと休み」** で `つづける` `BGM` `効果音` `全画面` `タイトルへ`
  `Esc キーでもつづける`
**③ 段階構造**: 眠りの深さ 3 段階（猶予 5 → 3 → 2 回）＝**失敗許容回数が段階とともに減る**。
これに「うす目（前ぶれ）→ まぶたぴくぴく（警告）」という**予告 → 本動作**の 2 拍子が重なる。
**④ 技法**: 発光（根元が金色に光る＝当たり位置の提示）/ ピンク発光＋4 秒の時限 /
リズム（いびき・Z のふくらみ）/ 段階ごとの失敗猶予 / スコア名を「ドパ」と呼ぶ語彙の演出 / 静かなポーズ画面。
**⑤ 出典**: 【一次/取得】ページ本文（HTTP 200）。実際の描画・音は未確認。

## 7. 事例6: パチンコ実機 — エヴァ15「虹」の段階
**① URL**: <https://www.dechau.com/news/single.php?id=7473>（ビスティ、2021.12.20 導入）
**② 見えるもの（二次/解析の数値）**: 「色」がそのまま**信頼度の段階**になっている箇所が複数ある。

| 演出 | 白 | 赤 | 虹 | それ以上 |
|---|---|---|---|---|
| 入賞時ランプフラッシュ（枠と初号機の目が発光） | 約7.2% | 約13.5% | **確変当り濃厚** | 覚醒目＝大当り濃厚 |
| 色保留 | 青 約0.5% / 緑 約1.5% | 約91.0% | **確変当り濃厚** | 点滅保留＝大当り濃厚 |
| 暗転タイトルランプ（決定色） | 1.9%（回転白→決定白） | 9.5% | **確変当り濃厚** | ― |

ステップアップ予告は 銀 SU1 約0.2% → SU5 約8.5%、金 SU5 約67.0%、金 SU5 ロング＝大当り濃厚。
キャラ連続予告は 1 段階目 約25.4% → 3 段階目 約53.3% → 4 段階目 大当り濃厚（最大 4 回）。
**全回転大当り**は「通常時の10R確変当りで発生。約1500個獲得に加えてST突入も確定」。
演出モードはノーマル／シンプルで、シンプルは演出頻度が低い代わりに**同じ演出の信頼度が上がる**。
**③ 段階構造**: 前兆予告（保留変化・先読み）→ リーチ前演出 → リーチ後演出 → 大当り → ST/時短。
[せせりくんの目次](https://pachiseven.jp/articles/detail/14705)がこの 4 層＋αを明示している。
**④ 技法**: 虹色（終端記号）/ 発光（枠・目）/ 保留変化（図柄の色が変わる）/ 段階アップ（SU1-5）/
連続予告（1-4 段階）/ 暗転 / シャッター（銀・金）/ 全回転 / 覚醒（虹のさらに上）。
**⑤ 出典**: 【二次/解析】でちゃう！PLUS、p-town、1geki、せせりくん。数値は各サイトが公表スペックを
まとめたもの。**当方は実機も動画も見ていない。**

## 8. 事例7: パチスロ — 色とフラッシュの段階
**① URL**: <https://www1.yamasa.co.jp/toranomaki/tr_nigt/ensyutu.html>（パチスロナイツ）
**② 見えるもの（二次/解析）**: 「リーチ目出現ゲームの**約30%が無演出**」＝**無演出も演出の一種**として
設計されている。予告音の強弱 × ナビフラッシュのランプ色で期待度が変わる:

| ランプ色 | 予告音 | 強予告音 |
|---|---|---|
| 青 | 2.8% | 18.9% |
| 黄 | 4.1% | 28.9% |
| 赤 | 8.9% | 88.2% |
| 緑 | 28.7% | 49.5% |
| 白 | 12.5% | 50.1% |

「ナビフラッシュは予告音と同時に発生し、成立役をランプ色で示唆。**対応役矛盾でボーナス濃厚**」
ウェーブフラッシュは「フラッシュの**数**で成立役を示唆」。
**③ 段階構造**: 無演出 → 予告音（弱/強）→ ナビフラッシュ（色）→ ウェーブフラッシュ（数）→ リーチ。
**段階が上がると「足される」のではなく「矛盾する」**（色と成立役が食い違う＝当たり）。
**④ 技法**: 予告音の強弱 / ランプ色 / フラッシュの回数 / 矛盾（論理的な外れ方）/ 無演出の意図的使用。
**⑤ 出典**: 【二次/解析】山佐 公式解析サイト。

## 12. 共通する段階構造の仮説
以下は**仮説**であり、規則へ上げるには `observations/` での追試が要る。
1. **強度は「色」で符号化される。** 白 → 赤 → 虹 の 3 色が基本で、虹は「これ以上は無い」終端記号。
   エヴァ15 では虹のさらに上に「覚醒目」があり、**終端の上に例外を 1 つ置く**のが定番の型。
2. **段階数は 4〜5 に揃う。** DOPA PONG の 5 段階、エヴァ15 の SU1-5、毛抜きの 3 段階＋予告。
   3 未満だと「上がった感」が出ず、6 以上だと覚えられない。
3. **上がり幅は非線形で跳ねる。** 倍率 ×1→×2→×5→×20→×100、信頼度 0.5%→1.5%→91%。
   隣の段階との差が**段階が上がるほど大きい**ほど、最後の一撃が強く見える。
4. **「静」を挟んで落差を作る。** 暗転・BGM 停止・無演出（スロの 30%）・「ひと休み」画面。
   強い演出は、直前の静けさの長さで強さが決まる。
5. **段階は常に「次がある」ことを見せる。** ラダーの常時表示（DOPA PONG）、保留の色、`NEXT 0`、
   ゲージ 0/100。**今どこにいるか**と**次はどこか**を同時に見せる。
